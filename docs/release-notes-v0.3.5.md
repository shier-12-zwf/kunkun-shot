# 困困截图工具 v0.3.5 发布说明

> 记录日期：2026-09-06
> 定位：截图工具栏一级长截图入口，macOS / Apple Silicon（arm64）本地固定身份签名预览包

本版在截图工具栏的“翻译”左侧加入“长截图”按钮，直接沿用当前选区进入可视化滚动拼接。翻译与目标语言选择器仍在一级工具栏，不必打开“更多”。v0.3.4 的实时长图预览和此前的贴图遮挡修复继续保留。

## 新的长截图入口与流程

1. 打开需要截取的网页、文档或列表，按 `⌘ ⇧ A`，框选内容区。
2. 点击工具栏中删除按钮右侧、翻译左侧的“长截图”。无需重新框选，也无需再点击“开始”。
3. 等待自动采集首帧和可以滚动的提示，将鼠标放回原页面选区内，缓慢、稳定地向下滚动。应用自动采集并拼接，不会代替你滚动页面。
4. 观察选区外的实时缩略预览、已保留帧数和输出尺寸。需要删帧、撤销/重做、修正固定头尾或裁边时，点击“调整”自动暂停；调整后点击“继续”。
5. 截取完成后点击“完成”，选择保存位置。保存成功后复制结果；取消保存或保存失败会保留现场供重试，不需要结果时点击“取消”。

原有主窗口、菜单栏和 `⌘ ⇧ L` 长截图入口继续可用。默认纵向，仅保留首帧时可切换横向；保留两帧后锁定方向。捕获的是原页面实时内容，普通截图中已有的标注和译文不会带入长图。

所有功能与详细步骤见 [完整使用指南](https://github.com/shier-12-zwf/kunkun-shot/blob/v0.3.5/docs/使用指南.md)，长截图见第 12 节。

## 防误触与布局适配

- 图片编辑和历史图片预览隐藏长截图按钮，并在动作执行层阻止从静态图片启动实时屏幕捕获，避免误抓桌面。返回当前截图并重新选区后恢复入口；复制等静态图片动作不受影响。
- 窄屏可使用带提示和可访问名称的图标按钮。880px 及以下将动作组置于第二行；放大镜倍率等附加控件展开后可按需换行，避免工具条内容和菜单被挤出屏幕。空间足够时保持单行。
- 回归覆盖按钮位置、当前选区与显示器传递、图片/历史动作门禁、返回当前截图恢复入口，以及不同宽度和附加控件下的布局边界。

## 已知边界

长截图仍为实验性能力。快速滚动、动画、吸顶区域、虚拟列表或复杂页面可能导致拼接失败或需要调整，应检查预览与保存结果。选区外没有足够空间时会隐藏预览并提示，不改变选区。工具条初次显示不主动抢焦点，优先点击“完成/取消”；`Enter` / `Escape` 仅在工具条获得焦点时有效，并非全局快捷键。

合成帧及渲染自动化不等于真实触控板/鼠标滚轮、多显示器硬件或所有网页的端到端验收，也不表示全应用没有其他缺陷。

DMG 外层不单独签名，内含 `.app` 使用固定本机开发证书签名；它不是 Apple Developer ID 分发签名，不启用 Hardened Runtime，未经过 Apple 公证，也没有 stapled ticket。该包仅供知情测试/预览使用，不声称已完成异机 Gatekeeper、权限或跨重启恢复验收。
