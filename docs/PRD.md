# 困困截图工具 · 产品需求文档（PRD）

> 说明：本 PRD 由**现有代码与功能逆向倒推**而成（reverse-engineered），用于沉淀产品定义、对齐后续迭代。
> 产品代号 `kunkun-shot`，当前源码版本 `v0.3.2`，平台 macOS（Electron）。
> 文档基于实际实现盘点（IPC 通道、渲染模块、配置项），非凭空设想；标注「⚠️ 待完善 / 已知限制」处为真实现状。

---

## 1. 产品概述

**一句话定位**：一款对标 PixPin 工作流的 macOS 本地截图工具，集「精确截图与标注 + 贴图与工作区 + 多语 OCR + AI 问答/翻译/可编辑表格/公式识别 + 可后编辑长截图 + 增强录屏 + 历史管理与多页 PDF」于一体，主打**本地、快捷、AI 增强**。

**产品形态**：菜单栏常驻 App + 全局快捷键唤起 + 浮层交互（截图蒙版 / 贴图窗 / AI 面板 / 长截图条 / 录屏条）。

**核心差异点**：
- 截图链路里**原生集成大模型**（DeepSeek、MiniMax 与通用 OpenAI 兼容文本服务），截完即可问 AI、翻译、润色、识别表格或公式；
- **截图原位翻译**（识别每行文字+坐标，译文盖回原文位置，沉浸式翻译式体验）；
- **本地优先**：OCR 可走本地 Tesseract，配置、历史与贴图工作区存本地，隐私可控；
- **离线公式贴图**：本地 KaTeX 实时预览并生成普通 PNG 贴图，不加载联网资源；
- **可自动化调用**：启动参数可直接进入区域/全屏/窗口/OCR/长截图/录屏流程，但仍保留 UI 与 macOS 权限边界。

---

## 2. 目标与非目标

**目标**
- 覆盖日常截图全链路：截 → 标注 → 用（复制/保存/贴图/OCR/AI）；
- 让「截图 + AI」一步到位，减少在多个 App 间来回切换；
- 快捷键驱动、浮层交互，尽量不打断用户心流。

**非目标（当前阶段不做）**
- 跨平台（当前仅 macOS）；
- 云端同步 / 多端协作；
- 团队/企业级权限与审计。

---

## 3. 目标用户与典型场景

**用户**：开发者、产品/运营、学生、内容创作者等高频截图人群（个人使用为主）。

**典型场景**
1. 截一段报错/代码 → 直接「问 AI」拿解法；
2. 截外文资料 → 「翻译」原位看译文；
3. 截图中文字 → 「OCR」提取可复制文本；
4. 截一张图钉在屏幕上对照操作（贴图）；
5. 截超出屏幕的长页面，暂停后删除错误帧、重新拼接并继续采集；
6. 录一段带点击/快捷键提示、摄像头和成片画笔的操作演示；
7. 回看/导出历史截图，或把多张历史图片合成多页 PDF；
8. 截取表格后直接编辑单元格并复制为 CSV、TSV 或 Markdown；
9. 识别截图中的公式为 LaTeX，或手工输入 KaTeX 公式生成离线贴图；
10. 使用脚本或启动器参数打开指定截图流程。

## 4. 功能需求

### 4.1 截图捕获（Capture）
- **区域截图**：全局快捷键 `Cmd+Shift+A` 唤起全屏蒙版 → 框选区域；支持选区调整、十字辅助线。
- **全屏截图** / **窗口截图** / **定时截图**（延时后自动截）。
- 多显示器支持（按显示器创建蒙版）。
- **精确尺寸**：按截图源像素输入宽/高，提供 640×480、1280×720、1920×1080、1080×1080 预设；支持自由、1:1、4:3、16:9 比例。屏幕坐标到源图坐标按 X/Y 两轴独立缩放，不能假设 Retina 或测试视口永远等比。
- 截图后行为可配置：是否自动复制、是否自动贴图、是否自动存历史。
- 通道：`CAPTURE_TRIGGER / CAPTURE_FULLSCREEN(_NOW) / CAPTURE_REGION / CAPTURE_WINDOW / CAPTURE_TIMED`。

### 4.2 标注编辑（Overlay 编辑器）
- 选区工具栏提供矩形、椭圆、箭头、直线、画笔、荧光笔、折线、文字、马赛克、真实高斯模糊、椭圆聚光灯、文字水印和序号标注，并支持颜色、撤销/重做。水印当前每次执行添加一个文字水印，固定 35% 透明度和 -20° 角度。
- **导出放大镜**：可移动、调整大小并选择 1.25×、1.5×、2×、3×、4×、6×、8× 倍率；镜片进入复制/保存结果，控制手柄只用于预览交互。
- 选区可移动、可调整；`V` 切换选择工具，`Enter` 执行默认动作，`Esc` 取消。
- **一级动作顺序**：第一位是「翻译」，目标语言选择器紧邻翻译按钮，随后是「OCR」；翻译及其目标配置均不再藏入「更多」。问 AI、表格/公式/条码结果、润色、保存和快速保存等低频项保留在「更多」中。

### 4.3 贴图（Pin）
- 把当前选区「贴」到屏幕上方常驻浮窗，便于对照；支持拖动、缩放、透明度、置顶、锁定、鼠标穿透、缩略、标题和恢复最近关闭项。
- 剪贴板入口 `Cmd+Shift+P` 可贴图片、文字、颜色或 Finder 文件。
- 图片贴图可使用画笔、直线、箭头、矩形、椭圆、文字和橡皮，并支持撤销/重做/清空。标注会合成到复制、保存、OCR、AI 和拖出文件的实际内容中。
- 图片贴图右键菜单提供交互裁剪、顺/逆时针 90° 旋转、水平/垂直翻转。变换前先合并当前标注并原子替换 PNG，因此属于破坏性栅格化；当前没有变换级撤销或自由角度旋转。
- **最小分组模型**：任一贴图可将当前全部贴图组成一组；拖动任一成员会整组同位移，可折叠/展开同组贴图或把当前贴图移出组，少于两张时自动解散。组 ID 随工作区持久化，折叠状态只保留在本次会话；当前不支持任意子集多选和对齐。
- **本地 LaTeX 公式贴图**：菜单栏托盘图标右键 →「LaTeX 公式贴图…」打开单例窗口；本地 KaTeX 实时预览，支持字号、文字色、透明/白色背景，通过按钮或 `Cmd/Ctrl+Enter` 生成普通 PNG 贴图。CSP 禁止联网且 `trust:false`；只支持 KaTeX 数学语法，不支持完整 TeX/任意宏包，生成后不保留可回编源码。
- 正常退出时会将打开的贴图与当前窗口状态原子持久化到用户数据目录，下次启动恢复；图片内容使用哈希校验，不信任同长度的损坏文件。
- 图片贴图的提交必须以即将显示的同一个 `<img>` 节点已完成加载/解码为成功条件，不能用独立探针成功代替可见节点成功；窗口渲染器每次完成载入后都重新接收该窗口的最新 payload，以覆盖意外刷新和恢复竞态。

### 4.4 OCR 文字识别
- 两种引擎（设置可选）：
  - **本地模式**（默认）：tesseract.js，语言包随包内置于 `tessdata/` 并预填缓存；支持简中、繁中、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语 9 种单语，以及除英语外各语言与英语组合，默认 `chi_sim+eng`；
  - **大模型模式**：按当前提供方的数据路由执行。MiniMax 可接收用户选择的截图并走视觉模型；DeepSeek 与通用 OpenAI 兼容提供方当前会先在本地 OCR，再只发送识别文字。提供方不支持视觉时不会静默改投其他端点。
- 本地语言数据缺失时明确失败，绝不回退到 CDN 或其他网络下载。
- 输出可复制文本；可一键转「翻译 / 润色 / 问 AI」。
- 通道：`OCR_RUN`；另有 `OCR_BOXES`（macOS Vision，输出每行文字+精确坐标，供原位翻译）。

### 4.5 AI 能力（问答 / 翻译 / 润色 / 表格 / 公式）
- **截图问 AI**：把选区图发给视觉模型，针对报错/题目/内容给出解释与解法（默认提示词可配）。
- **翻译**、**润色**：基于 OCR 文本或选区图。
- **提供商模式**：DeepSeek（文本任务；截图先走本地 OCR）、MiniMax（`MiniMax-M3`，支持直接看图），以及通用 OpenAI 兼容文本服务（硅基流动 / 通义千问 / Kimi / 自定义端点）。
  - 模式：`deepseek` / `minimax` / `openai` / `auto`。`auto` 是失败关闭的固定路由：纯文本任务只发 DeepSeek，看图任务只发 MiniMax，必须同时配置两者。不会用其他服务商的残留 Key 静默改投端点。
- 流式输出；思考过程控制（翻译/OCR 只出结果，问答可展示思考）。
- **AI 表格识别**：模型输出 GitHub Flavored Markdown 或 CSV，结果解析为纯文本可编辑单元格；最多 500 行、100 列，单元格 10,000 字符、源文本 1,000,000 字符。编辑后可复制 CSV、TSV 或 Markdown，CSV/TSV 会对以 `= + - @` 开头（含前导空白）的单元格添加前导单引号，降低电子表格公式注入风险；当前不提供表格文件导出。
- **AI 公式识别**：输出 LaTeX，不解题或自行补全缺失符号。
- 表格/公式的任务模式由渲染层选择，固定提示词保留在主进程。视觉提供方直接看图；纯文本提供方只接收本地 OCR 结果，因缺少单元格坐标而可能无法可靠恢复复杂表格。

### 4.6 截图原位翻译（沉浸式）⚠️ 持续打磨中
- 截图一级工具栏的**第一个动作**是「翻译」：系统 Vision OCR 识别每行文字+坐标 → 大模型逐行翻译 → **译文按坐标盖回每行原文位置**。
- **目标语言可选**：翻译按钮旁直接提供紧凑控件，支持中/英/日/韩/法/德/西/俄 共 8 种，默认中文；选择即写入 `translate.target` 配置，保存失败必须显示反馈。
- **保存/复制含译文（已实现）**：导出图（`composeImage`）会把译文层合成进 canvas，保存与复制得到的图即带覆盖译文，不再只是屏幕显示层。
- 已知点：大留白/带固定水印的页面，坐标对齐受限。

### 4.7 长截图（滚动拼接）⚠️ 已知限制
- `Cmd+Shift+L` 唤起 → 框定区域 → 选择纵向或横向 → 用户沿单一方向匀速滚动 → 自动逐帧抓取并按重叠拼接成长图；支持开始、暂停和继续。
- 长截图与录屏控制条必须完整落在目标显示器边界内；优先位于选区下方，空间不足时放到上方，整屏选区、副屏负坐标和控制条宽于显示器时仍须钳制为可见尺寸与位置。
- 保留原始帧与 segment 时间线。暂停后可从下拉框删除任意首/中/尾帧并事务式重新拼接，支持撤销/重做；删段后可继续采集。若剩余帧没有可靠重叠，本次操作取消并保留上一个正确结果。
- 抓帧、删帧、固定区域、撤销和重做均以“模型变更 + 新画布合成”作为一个事务；合成、画布分配、ImageData 或像素写入失败时必须回滚模型、撤销/重做栈和原始帧集合，保持上一画面与下一次导出一致。
- 原始帧只保留当前时间线、撤销栈和重做栈仍可到达的条目；新帧使重做分支失效后应立即回收孤儿帧。若可撤销历史会突破源像素预算，可从最旧快照开始缩短撤销深度，但不得淘汰当前帧或损坏当前输出。
- 固定顶栏/底栏可自动建议像素值，也可手工输入；用户确认应用后重新拼接，固定带只保留一次并可继续采集。它不是可视化拖拽或通用语义识别；最终结果的顶部/底部裁切仍是独立操作。
- RGB 三通道空白、反向、匹配歧义、宽度/DPR 变化等坏帧会被明确拒绝且不污染上一个结果；恢复原方向/尺寸后可继续。单次会话只锁定一个方向，并受帧数、源像素与内存预算限制。
- 已知限制：动态内容、来回滚动、多滚动区域、重复/纯色内容、复杂固定水印/悬浮层仍可能无法可靠匹配；应用不会自动驱动目标页面滚动。

### 4.8 录屏（Recording）
- `Cmd+Shift+R` 录制选定区域，默认保存无需外部 FFmpeg 的未剪辑 WebM；H.264 MP4、GIF 与裁剪调用用户另装且能力匹配的系统 FFmpeg。可配 fps（默认 12）与是否转 GIF；无 FFmpeg 时 GIF 请求回退 WebM，裁剪需确认保存完整 WebM 或取消。
- 支持暂停/继续、取消、剪辑、超限保护和保存失败后重试；时长以有效录制时间计算，不把暂停时间算入。
- 系统声音与麦克风可独立选择，默认都关闭；两者同时开启时混成一条录制音轨。已选音源权限被拒或实际不可用时明确失败，不静默退化成无声录屏。
- 录制开始前可选择**点击提示、快捷键提示、圆形摄像头画中画**；摄像头独立申请且不采集摄像头音频，授权失败可重试。摄像头断开时释放其资源并提示，但屏幕录制仍可停止和保存。
- 录制中可开启「成片画笔」并清除笔迹。画笔通过输入事件绘制，点击/快捷键提示、笔迹与摄像头都会烘焙进编码结果，不是悬浮在桌面的独立直播标注层。
- 点击/快捷键由原生事件 helper 提供，通常需要 macOS 辅助功能权限。命名特殊键会显示；字母数字只在与 Command/Control/Option 组成快捷键时显示，普通未修饰输入不会被捕获或输出。helper 运行中失败会明确关闭提示，但不终止录屏。
- 输出裁区、摄像头、事件提示、画笔和文件名尺寸均以真实桌面媒体流像素为基准，X/Y 独立映射以适配 Retina、多显示器和非等比情况；屏幕源按 display ID/索引匹配，不依赖返回顺序。

### 4.9 历史记录（History）
- 列表/查看/搜索/筛选/复制/删除/批量删除/导出/清空。“自动保存到历史”默认关闭，但成功执行“保存”或“快速保存”时仍会在历史库另存一份私有副本。
- 可把选中的历史图片按调用/选择顺序合成真正的多页 PDF；最多 100 页、输入总量 256 MiB。视频、缺失项和越界输入会明确拒绝。单张截图的 PDF 导出仍是单页，两条路径不混淆。
- 清空历史只删除历史库的应用副本，不会删除用户另存到其他目录的文件。
- 历史按日期分组、旧日期默认折叠。
- 加载错误必须与真正的空历史区分，并提供可重试状态；复制、导出、删除、批量操作和清空必须检查 IPC 的实际返回值，部分成功时报告实际完成数量，不得在 Promise 解析但业务失败时误报成功。
- 通道：`HISTORY_LIST/GET/DELETE/EXPORT/CLEAR/CHANGED`。

### 4.10 主界面与快捷入口
- **菜单栏托盘**常驻，**Popover** 快捷面板（`POPOVER_TOGGLE`）。
- **长截图一级入口**同时位于主页“快捷截图”和菜单栏左键快捷面板，并可由全局快捷键 `Cmd+Shift+L` 进入。
- **主窗口**含截图、历史、AI 工作台和设置四页；AI 工作台内部为三栏布局，历史栏和预览栏可折叠。
- 剪贴板集成：写图/写文/读图（`CLIPBOARD_*`）；保存到本地、可选保存目录（`CHOOSE_SAVE_DIR`）。
- **IPC 结果契约**：打开设置/AI 等请求只返回可结构化克隆的确认对象，不得把 `BrowserWindow` 等 Electron 对象回传渲染层；主窗口截图入口等待业务结果并区分成功、取消、忙碌和错误，剪贴板与配置操作只在明确成功后显示成功反馈。

### 4.11 图片导出、文件名模板与启动参数
- 截图可原子写入 PNG、JPEG、WebP、BMP、AVIF 或单页 PDF；快速保存、保存对话框默认格式和历史批量导出共用配置。编码失败不会把临时或半成品冒充为成功文件。
- 截图默认文件名 `困困截图-{timestamp}`，录屏默认 `困困录屏-{timestamp}`；可配置 `{datetime}`、`{date}`、`{time}`、`{timestamp}`、`{type}`、`{index}`、`{width}`、`{height}`。路径分隔符、控制/非法字符、未知或不完整变量和超长输入会被拒绝；冲突文件从 `-2` 开始追加后缀。
- `--capture=region|fullscreen|window|ocr|long|record` 可从首次或第二次启动进入对应权威流程；`--delay=1..300` 只允许区域或全屏。重复、未知、非整数或越界参数失败关闭。
- 启动参数不是无头文件导出 API；对应流程仍使用图形界面并受 macOS 权限约束。

## 5. 配置 / 设置需求

| 分类 | 配置项 | 默认值 |
|---|---|---|
| 快捷键 | 截图 / 贴剪贴板 / 录屏 / 长截图 / OCR | `Cmd+Shift+A / P / R / L / O` |
| AI | 供应商 provider | `deepseek`（可 `minimax` / `openai` / `auto`） |
| DeepSeek | baseUrl / 文本模型 / 视觉模型 / 各提示词 | `https://api.deepseek.com/v1`、`deepseek-v4-flash` / `deepseek-v4-pro` |
| MiniMax | baseUrl / 文本 / 视觉模型 / apiKey | `https://api.minimaxi.com/v1`、`MiniMax-M3` |
| OpenAI 兼容 | preset / baseUrl / 文本模型 / apiKey | `siliconflow`、`deepseek-ai/DeepSeek-V3`；亦可选通义千问、Kimi 或自定义端点 |
| OCR | 引擎(local/model) / 语言 | `local`、`chi_sim+eng`；9 种单语及 8 种“对应语言+英语”组合 |
| 原位翻译 | 目标语言 `translate.target`（中/英/日/韩/法/德/西/俄） | `中文` |

## 6. 非功能需求

- **平台**：macOS（darwin）；Electron 桌面应用。
- **隐私/本地优先**：OCR 可全本地；配置、历史与贴图工作区存用户目录。API Key 只有在 Electron `safeStorage` 成功加密后才落盘；安全存储不可用或加密失败时明确拒绝保存。
- **权限**：截图/录屏/长截图需“屏幕录制”权限（TCC）；只在用户显式开启时请求系统音频、麦克风、摄像头或录屏点击/快捷键所需的辅助功能权限。摄像头媒体流与桌面音频分离。
- **发布真实性**：`dist:mac:local` 默认要求固定的本机代码签名证书，以维持同一台 Mac 上开发安装更新后的 TCC 身份；该路径不公证、不启用 Hardened Runtime，不等于 Developer ID 或正式发布。`dist:mac:adhoc` 只用于一次性隔离测试，不能覆盖日常安装版本、交付更新或保留 TCC 权限。`dist:mac:release` 是必须具备 Developer ID 与一套完整公证凭据的失败关闭流水线，会验证 Developer ID、Team ID、Hardened Runtime、Gatekeeper、stapled ticket、DMG/ZIP 完整性与 SHA-256。当前仓库没有 Apple 凭据、公证记录或已验证正式产物，不声称已正式签名/已公证。
- **性能口径**：实际延迟取决于屏幕尺寸、显示器、OCR 语言、图像复杂度与 AI 服务；当前不承诺固定抓帧或 OCR 耗时。macOS Vision 帮助程序在打包前构建并随应用携带，不应把开发环境的现场 Swift 编译当作产品性能承诺。
- **交互与反馈**：全局快捷键、菜单栏和启动参数唤起；截图蒙版、贴图和录屏控制条按各自的交互契约管理焦点与窗口。IPC 拒绝或返回业务失败时必须提供可理解、可访问、可重试的反馈，不能吞错或把失败显示为空状态/成功状态。

## 7. 技术架构（简）

- **主进程**：`main.js`（窗口/快捷键/截图/AI/OCR/历史调度）、`windows.js`（各窗口）、`config.js`、`deepseek.js`（AI 调用）、`ai-recognition.js`（AI 表格/公式任务边界）、`ocr.js`/`ocr-worker.js`（Tesseract）、`ocr-boxes.js`（macOS Vision 出坐标）、`image-export.js`、`history-pdf-export.js`、`media.js`、`history.js`、`pin-workspace-store.js`、`launch-actions.js`。

## 8. 已知限制与后续迭代

**已知限制（诚实标注）**
1. 长截图虽支持删段重拼、继续和固定顶/底区域，但对动态内容、来回滚动、多滚动区域、重复/纯色内容和复杂固定水印仍不可靠；单次会话只允许一个方向，宽度/DPR 改变后必须恢复才能继续，也不会自动滚动目标页面。
2. 原位翻译在大留白/复杂排版下坐标对齐受限。（保存/复制不含译文的限制已解除，见 §4.6。）
3. 系统声音、麦克风、摄像头、辅助功能事件、多显示器/Retina、TCC、窗口截图、AVIF/PDF 的 Preview/Finder 兼容性、贴图变换/分组跨重启，以及实际 AI 凭据路由都需目标 macOS 真机验收；自动测试不能代替。
4. AI 表格/公式识别受截图清晰度和模型能力影响；纯文本提供方仅收到本地 OCR 文本，不保证复杂表格结构还原。
5. 稳定本地证书签名只用于开发安装与 TCC 身份连续性，不等于 Developer ID 或公证；没有 Apple 凭据和正式产物证据时，不得将任一流水线的存在写成“已正式签名/已公证”。
6. 贴图分组只覆盖“当前全部贴图”，暂无任意子集多选/对齐；图像变换会栅格化且无变换级撤销。公式贴图只支持 KaTeX 数学语法，生成后不可回编。
7. 录屏不支持动态 WebP、进程崩溃恢复或中段时间线编辑；普通未修饰文字键不会被录制提示捕获。条码可用制式依赖 Chromium/系统能力。

**后续迭代候选**
- 原位翻译：~~目标语言选择器~~（已做）、~~把译文合成进导出图~~（已做）、对齐精修；
- 长截图：复杂悬浮层/重复内容策略，以及有明确用户收益后再评估受限自动滚动；
- 贴图：任意多选/对齐、变换撤销、关注区域和图像滤镜；
- 录屏：WebP、异常恢复和中段时间线编辑；
