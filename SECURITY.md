# 安全政策 / Security Policy

## 中文

### 报告安全漏洞

请不要在公开 Issue、讨论区、截图、录屏或日志中提交漏洞细节、API Key、访问令牌、个人数据或其他秘密。

1. 优先打开仓库的 **Security** 页面，并使用 **Report a vulnerability**（GitHub Private Vulnerability Reporting）私密提交。
2. 如果该入口不可用，请新建一个**不含漏洞细节**的普通 Issue，只说明“需要私密安全报告渠道”。维护者会在 GitHub 可用能力范围内建立私密沟通方式。
3. 普通、非敏感的缺陷可以直接提交 Issue。

一份有帮助的私密报告应包含：受影响版本或提交、运行环境、最小复现步骤、实际影响，以及建议的缓解方式（如有）。请只使用测试账户和脱敏数据。

维护者会尽力确认报告、评估影响并协调修复，但目前不承诺固定响应时限。修复公开前，请不要披露未修复漏洞。

### 支持范围

安全修复优先面向默认分支的最新版本。旧版本可能不会获得回补。当前项目以 macOS 为首要平台；未列入发布检查清单的系统或构建不应被视为已验证。

## English

### Reporting a vulnerability

Do not disclose vulnerability details, API keys, access tokens, personal data, or other secrets in a public issue, discussion, screenshot, recording, or log.

1. Prefer **Security → Report a vulnerability** in this repository, which uses GitHub Private Vulnerability Reporting.
2. If that entry is unavailable, open a regular issue **without technical or sensitive details** and ask the maintainers to establish a private reporting channel.
3. Regular, non-sensitive bugs may be reported in public issues.

A useful private report includes the affected version or commit, environment, minimal reproduction steps, practical impact, and a suggested mitigation when available. Use test accounts and redacted data only.

Maintainers will make a best-effort attempt to acknowledge, assess, and coordinate a fix, but no fixed response SLA is currently promised. Please avoid disclosure until a fix is available.

### Supported versions

Security work targets the latest version on the default branch. Older versions may not receive backports. This project is macOS-first; systems and builds not covered by the release checklist should not be considered verified.
