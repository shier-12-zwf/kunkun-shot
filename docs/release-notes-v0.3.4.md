# 困困截图工具 v0.3.4 发布说明

> 记录日期：2026-09-05
> 定位：可视化滚动长截图，macOS 本地签名预览包

本版把长截图从展开的参数面板改为“框选后直接滚动”的可视化操作。此前 v0.3.3 的贴图遮挡修复、截图工具栏一级首项“翻译”及目标语言选择器保持不变。

## 新的长截图流程

1. 打开需要截取的页面，按 `⌘ ⇧ L`，或点击主窗口的“长截图”。
2. 框选要截取的内容区。松开鼠标后自动采集首帧，无需再点“开始”。
3. 白色边框保留在选区周围；把鼠标放回原页面，缓慢向下滚动。应用自动采集和拼接，不会代替你滚动。
4. 在选区外查看绿色边框的实时拼接预览、已保留帧数和输出尺寸。选区辅助层在原生窗口层面穿透鼠标，不拦截原页面的滚动。
5. 截到需要的位置，点击“完成”。保存成功后会复制结果；取消保存可继续调整，复制失败时会保留结果并允许重试。

默认工具条仅保留方向、暂停/继续、调整、完成和取消。点击“调整”会先暂停，再展开片段删除、撤销/重做、固定顶部/底部与导出裁边；点击“继续”收起面板并保留已有结果。只有首帧时可以切换横向，加入第二帧后锁定方向。

预览使用有尺寸上限的缩略图，不降低最终导出分辨率。选区外空间不足时会隐藏预览并提示，不改变你的选区；工具条与选区重叠时，抓帧前临时隐藏工具条，避免将其截入。建议框选时给旁边留一些空位。

优先使用“完成/取消”按钮。工具条初次显示不主动抢焦点，`Enter` / `Escape` 仅在工具条获得焦点时有效，并非全局快捷键。

所有功能与详细操作见 [完整使用指南](https://github.com/shier-12-zwf/kunkun-shot/blob/v0.3.4/docs/使用指南.md)，长截图见第 12 节。

## 同步修复的稳定性问题

- 修复第二帧追加后“调整”按钮可能持续灰置；测试明确覆盖不先暂停、不等待下一次空闲抓帧就点击调整。
- 修复 CSS 显示规则可能让带 `hidden` 的高级控件重新显示。
- 选区辅助层与控制条成组关闭，取消、窗口销毁或渲染进程异常后不接受迟到帧。
- 捕获范围使用主进程登记的选区，不信任渲染进程临时传入的范围；显示器位置或缩放改变时明确停止该次捕获。
- 相同预览不重复传输，窗口边界不变时不重复移动窗口。删除、撤销和裁边会更新缩略预览，原始导出像素保持独立。

## 已知边界

长截图仍为实验性能力。快速滚动、动画、吸顶区域、虚拟列表或复杂页面可能导致拼接失败或需要调整；应检查预览和保存结果。此次合成帧渲染测试不等于真实触控板/滚轮、多显示器硬件或所有网页的端到端验收，也不表示全应用没有其他缺陷。

DMG 外层不单独签名，内含 `.app` 使用固定本机开发证书签名；它不是 Apple Developer ID 签名，不启用 Hardened Runtime，未经过 Apple 公证，也没有 stapled ticket。该包仍供知情测试/预览使用，不声称已完成异机 Gatekeeper、权限或跨重启恢复验收。
