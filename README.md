# 困困截图工具

简体中文 | [English](README_EN.md)

一款以 macOS 为首要平台的开源 Electron 截图工具：区域截图与标注、贴图钉屏、多语种离线 OCR、二维码/条码识别、可编辑长截图、带摄像头与操作提示的区域录屏，以及可选的 AI 问图、翻译、表格和公式识别。

> 当前源码版本：`v0.3.4`，仍为早期预览版。源码和自动测试可用不等于所有真机流程已经验收。应用二进制须从发布源码全新构建并完成负向扫描后才可上传；通过门禁后，GitHub Release 除平台自动生成的源码归档外，只附一个供知情测试的 DMG，不附应用 ZIP。该 DMG 外层不单独 codesign，内含的 `.app` 使用固定本机开发证书签名，但不是 Apple Developer ID 签名，且不经过 Apple 公证、没有 stapled ticket。项目不声称支持 Windows/Linux。发布证据与风险边界以 [发布检查清单](docs/RELEASE_CHECKLIST.md) 为准。

第一次使用请阅读 [完整使用指南](docs/使用指南.md)；想了解与 PixPin 的逐项差距、证据和后续优先级，请看 [竞品对比与改进报告](docs/PixPin-竞品对比与改进报告.md)。v0.3.4 改为可视化滚动长截图，操作见下方说明与使用指南第 12 节，验证记录与安装包校验和见 [v0.3.4 发布说明](docs/release-notes-v0.3.4.md)；此前贴图显示热修复记录保留在 [v0.3.3 发布说明](docs/release-notes-v0.3.3.md)，完整版本历史见 [更新日志](CHANGELOG.md)。

## 能做什么

- 区域、窗口、全屏和延时截图；选区支持独立 X/Y 源像素映射、精确宽高、常用尺寸预设、自由/1:1/4:3/16:9 比例和键盘微调。
- 矩形、椭圆、箭头、直线、画笔、荧光笔、折线、文字、马赛克、序号、真实模糊、聚光灯、文字水印和可导出放大镜；支持移动/缩放、倍率调节和撤销/重做。
- 截图编辑器的第一个一级动作是“翻译”，目标语言选择器紧邻按钮且无需打开“更多”，“OCR”随后；贴图、复制和取消也在一级，低频动作收进“更多”。
- 将图片、文字、颜色或 Finder 文件贴到屏幕；图片贴图可标注、裁剪、90° 旋转、水平/垂直翻转，多张贴图可分组移动、折叠/展开与解组；还可用本地 KaTeX 生成 LaTeX 公式贴图。图片会先完成解码再把同一显示节点提交到窗口，窗口重新载入时会重新注入最新内容，降低偶发空白风险；复制、保存、OCR、AI 和拖出使用合成结果，正常退出会恢复工作区。
- 本地 OCR 支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语和葡萄牙语，以及预置的“单语种 + 英语”组合；语言数据随包提供，不会联网下载。
- 自动识别二维码与浏览器支持的常见条码；结果和失败状态常驻，可手动用原分辨率选区重试。
- 截图历史保存在 Electron 用户数据目录的 `history/`。自动入历史默认关闭，但成功执行“保存”或“快速保存”时仍会在历史库中另存一份；清空历史只删除历史库副本，不会删除用户另存到其他目录的文件。历史支持搜索、筛选、复制、导出和批量删除。
- 截图可导出 PNG、JPEG、WebP、BMP、AVIF 或单页 PDF；PNG、JPEG、PDF 无需外部 FFmpeg，WebP、BMP、AVIF 需要用户另行安装且含对应编码器的系统 FFmpeg。截图与录屏可分别设置文件名变量模板，同名文件自动追加序号。历史页可将最多 100 张图片按选中顺序合并为多页 PDF。
- 区域录屏默认保存未剪辑 WebM，无需外部 FFmpeg；GIF、H.264 MP4 和录屏裁剪需要用户另行安装、并具备所需编码器/滤镜的系统 FFmpeg。无 FFmpeg 时，GIF 请求自动回退 WebM；裁剪请求会要求确认保存完整未剪辑 WebM 或取消。系统声音和麦克风独立可选，还可把摄像头画中画、鼠标点击、特殊按键/修饰键快捷键及画笔标注写入成片。录制裁剪与操作提示按实际视频像素做 Retina/多屏映射。
- AI 工作台支持 OCR 后问答、翻译、总结和润色；AI 表格结果可逐单元格编辑，并复制为 CSV、TSV 或 GFM Markdown，导出时防止常见的表格公式注入。公式识别输出 LaTeX；支持视觉的模型可直接接收用户选中的截图。
- 长截图框选后自动采集首帧，保留透明穿透的选区边框；直接在原页面人工滚动，选区外实时预览拼接结果。支持纵向/横向、失败后继续、删除错帧并从原始帧重新拼接、撤销/重做、固定顶部/底部区域自动建议与手动值，以及导出裁剪。重拼失败会回滚到上一份可导出结果，失去引用的原始帧会释放以守住内存预算。它仍为实验性能力，动态或复杂滚动内容仍需人工复核。

### v0.3.4：可视化滚动长截图

基本流程是：框选内容区 → 自动采集首帧，无需点“开始” → 在原页面向下滚动 → 查看选区外的实时缩略预览 → 点击“完成”，保存成功后复制结果。应用自动采集和拼接，不会代替你滚动页面。

默认只显示方向、“暂停/继续”、“调整”、“完成”和“取消”。点击“调整”会自动暂停，再展开片段编辑、固定头尾和导出裁剪；点击“继续”会收起调整面板。默认纵向，需要横向时应在只有首帧、尚未拼入新内容时切换；保留两帧后方向锁定。

选区边框与预览不拦截原页面的鼠标滚动，工具条初次显示不主动抢焦点。选区外空间不足时会隐藏预览并提示，不缩小或移动你的选区；工具条也会保持在当前显示器内，若与选区重叠，抓帧时会临时隐藏以避免被截入。优先使用“完成/取消”按钮；`Enter` / `Escape` 仅在工具条获得焦点时有效，不是全局快捷键。自动化检查不代替目标 Mac 上的真实滚轮、多屏与复杂页面验收。

## 快速开始

需要：

- macOS（当前主要开发与支持平台）
- Node.js 22.12 或更高版本
- npm
- 首次安装依赖时可访问 npm
- 可选：若要导出 WebP/BMP/AVIF、GIF、H.264 MP4 或裁剪录屏，请另行安装系统 FFmpeg，并确认该构建包含目标格式所需的编码器/滤镜；应用及其安装包不内置 `ffmpeg-static` 或独立 FFmpeg 命令行程序

```bash
git clone https://github.com/shier-12-zwf/kunkun-shot.git
cd kunkun-shot
npm ci
npm run test:all
npm start
```

默认会打开主窗口，同时提供菜单栏入口。若全局快捷键已被系统或其他应用占用，请在设置页修改。

### macOS 屏幕与音频权限

截图、长截图和录屏需要 **系统设置 → 隐私与安全性 → 屏幕录制** 权限。开发模式可能显示为 Electron 或启动应用的终端。

1. 启动一次应用并触发截图。
2. 在系统设置中授予对应进程权限。
3. 完全退出 Electron/应用，再重新执行 `npm start`。

没有权限时可能只能捕获桌面壁纸、黑屏或空白画面。授权变化通常要重启进程才会生效。

录屏的系统声音与麦克风默认关闭，只有在设置中分别开启时才会请求 macOS 对应权限。如果用户明确要求的音频源不可用或被拒绝，录制会明确失败，不会静默产生无声视频。这两条音频链路仍必须在目标 macOS 版本和实际签名产物上手工验收。

## 启动参数（自动化）

开发模式和已打包应用都可通过启动参数进入同一套受控截图流程。开发模式示例：

```bash
npm start -- --capture=region
npm start -- --capture=fullscreen --delay=5
npm start -- --capture=window
npm start -- --capture=ocr
```

`--capture` 支持 `region`、`fullscreen`、`window`、`ocr`、`long` 和 `record`。`--delay=1..300` 只能与 `region` 或 `fullscreen` 组合，单实例应用的第二次启动也会处理这些参数。这不是无头导出 API：截图仍需要图形界面和相应的 macOS 权限。重复、未知或越界参数会直接报错，不会猜测执行。

## AI 与数据边界

AI 功能不是截图本身的必需条件。仅使用本地截图、标注、贴图和本地 OCR 时，不需要填写 API Key。

启用 AI 前请理解以下数据流：

- 文本任务会把提示词、用户输入或 OCR 得到的文字发送到当前配置的服务商 Base URL。
- 视觉任务会把用户主动选择的截图发送给支持图片输入的服务商。当前路由中，MiniMax 用于直接看图；纯文本提供商会先在本地 OCR，再发送识别出的文字。
- AI 表格/公式识别遵循同一边界：视觉路由发送用户选中的图，纯文本路由只发送本地 OCR 文本；后者可能无法可靠恢复复杂表格结构。
- “智能分流”采用固定路由：纯文本任务只发往 DeepSeek，看图任务只发往 MiniMax，必须同时配置两者。缺少本次任务对应的配置时请求会明确停止，不会利用其他服务商的残留 Key 改投端点。
- 测试连接和拉取模型列表也会向配置的服务端发起网络请求。
- 本地 OCR 只读取仓库/应用资源中的 `tessdata`，可选 `chi_sim`、`chi_tra`、`eng`、`jpn`、`kor`、`fra`、`deu`、`spa`、`por` 及预置的各语种 `+eng` 组合。所需语言数据缺失时会明确失败，绝不会从 CDN 或其他网络端点回退下载。
- API Key 仅在 Electron `safeStorage` 成功加密后才会落盘；系统安全存储不可用或加密失败时，保存会明确报错，绝不会以明文落盘或误报成功。

不要把含个人信息、商业秘密或第三方受限内容的截图发送给不受信任的模型服务。使用服务商即同时受其隐私政策、数据保留规则和计费条款约束。

## 项目结构

```text
src/
├── main/       Electron 主进程：捕获编排、配置、历史、OCR、媒体与 AI 请求
├── preload/    contextBridge 白名单 API
├── renderer/   无框架 HTML/CSS/JavaScript 界面
└── shared/     IPC 通道与默认配置
test/           Node 回归测试
tessdata/       本地 OCR 语言数据
docs/           产品说明与发布检查资料
```

渲染层不开启 Node 集成，只通过 preload 暴露的 `window.kkapi` 与主进程通信。项目没有前端打包步骤，Electron 直接加载本地 HTML/CSS/JavaScript。

## 已知限制

- 当前仅把 macOS 作为支持与验收重点；代码中出现的通用 Electron API 不构成跨平台支持承诺。
- 长截图的自动采集不等于自动滚动，仍需用户人工滚动，也仍是实验性实现；动画、持续刷新、反向滚动或复杂嵌套滚动容器可能无法可靠拼接。固定顶部/底部已有辅助处理，但仍需人工确认。选区外无足够空间时不会显示缩略预览，也不会擅自改变选区。
- 可选的 FFmpeg 转换依赖用户安装的具体构建；只发现 `ffmpeg` 可执行文件不代表其中一定包含 WebP/AVIF/H.264/GIF 所需的编码器或滤镜。GIF 转换会消耗较多时间和空间，高分辨率、长时间录屏尤其明显。
- 系统声音、麦克风、摄像头热拔插、混合 DPI 多屏、AVIF/PDF 在系统预览/Finder 中的兼容性，以及贴图工作区跨重启恢复，都需在目标 macOS 真机上验收。
- 录屏“成片画笔”会直接写入录制文件，不会另建一层透明窗在桌面上实时预览；摄像头在录制中断开时会继续屏幕录制，但不在同一次录制中热重连。
- 全局快捷键可能与系统或其他应用冲突。
- OCR 精度取决于图像质量、语言数据和版面；AI 结果也可能错误。
- 当前没有应用内自动更新或已公证的公开安装包；v0.3.4 只有在全新 DMG 通过发布清单后才会附一个知情测试包，其外层不单独 codesign、内含 `.app` 使用固定本机开发证书签名，不附应用 ZIP，更新仍需人工安装。
- 尚未完成的自动或真机验证项目以发布检查清单中的未勾选项为准。
