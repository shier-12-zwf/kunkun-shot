# v0.3.6：长截图实际滚动热修复

日期：2026-09-06。平台：macOS / Apple Silicon（arm64）。

## 修复内容

1. **停在 1 帧**：旧版会将静止的稀疏页面误判为固定区域；758px 选区可产生顶部、底部各 227px 的任意建议，并直接暂停。现在完全相同的帧保持等待，不重复拼接；固定区域只有在边界明确、正文确有可靠位移时才会自动处理，不再为了建议打开调整面板。
2. **滚动后无法接续**：旧版稀疏网格可能漏掉文字，并将纯白页边当成可靠重叠。现在使用有界的正文特征行复核，两侧候选都必须有内容证据；仍拒绝真正无法区分的重复内容，不强制选择最长重叠。
3. **白边、遮罩截入结果**：本机 macOS 将辅助窗口的实际原点从 y=0 调整到菜单栏下的 y=38，旧版仍以原位置绘制。现在根据原生内容窗口的真实原点补偿选区、四周遮罩与预览，并在窗口位置改变时同步；捕获范围不随之移动。抓帧中的窗口移动或尺寸事件只校正辅助层坐标，不提前展开工具栏，避免工具栏侵入选区。

固定栏自动处理和第二帧接入是同一事务：内存或像素预算不满足、渲染失败时回滚，保留原先可导出的画面。

## 使用流程

按 `⌘ ⇧ A` 框选需要滚动的正文 → 点击翻译左侧的“长截图” → 将鼠标放回选区内，缓慢向下滚动 → 观察帧数和长图高度增长 → 点击“完成”保存并复制。

无需填写固定头尾数值才能继续。只有需要人工修正时才点击“调整”。长截图仍由你滚动原页面，应用负责采集和拼接。完整功能说明见 [使用指南第 12 节](使用指南.md#12-长截图)。

## 自动化证据与边界

- 本轮源码 `npm run test:all` 通过：540 项 Node 测试、Electron 正常与故障注入冒烟、截图工具栏回归、7 组原有长截图渲染回归，以及 15 项新增真实 DOM 滚动检查。
- 新回归通过真正的 Chromium wheel 输入滚动普通中文网页，再抓取实际渲染画面交给生产长截图代码；不是递增预制帧索引。白底文章、深色聊天、固定导航三种页面各连续滚动 3 次，输出从 650 增长到 1010px。最终 3 张 PNG 与独立完整页面合计 3,333,000 个像素逐像素一致，重复运行结果相同。
- `--baseline=v0.3.5` 在旧发布代码上重复复现：页面 scrollTop 仍为 0，第 2 次采集就自动暂停，只有 1 帧。
- 独占运行的原生抓屏检查通过：生产窗口工厂、真实 macOS desktopCapturer、80 DIP 滚动使结果从 840×520 增长到 840×680；选区对齐、辅助层排除、重叠工具条隐藏、焦点保持、导出与窗口清理通过。已有屏幕权限为 granted，测试不请求或更改权限。
- 曾在其他 Electron 回归并发时出现测试窗口失焦而判红；未放宽断言，后续无其他 Electron 进程的串行复测通过。原生可见检查应独占执行，不能与冒烟/界面测试同时运行。
- 隐藏 DOM 测试不证明系统鼠标穿透；原生测试的滚动输入也只定向发送给测试自有窗口，**不声称已经验证物理鼠标/触控板穿透、多屏硬件或所有动态网页**。视频、轮播、快速滚动、延迟加载和复杂嵌套容器仍需复核结果。

复验命令：

```sh
npm run test:all
# 预期失败，用于证明旧版确实存在问题：
node scripts/test-longshot-scroll.js --baseline=v0.3.5
# 默认只查权限，不显示窗口；显式参数才短暂显示本测试自己的窗口：
node scripts/test-longshot-native.js
node scripts/test-longshot-native.js --visible-owned-fixture
# 安装后复验实际 app.asar 中的生产渲染代码（隐藏窗口）：
KK_LONGSHOT_SCROLL_RENDERER_DIR='/Applications/困困截图工具.app/Contents/Resources/app.asar/src/renderer/longshot' npm run test:longshot:scroll
```
