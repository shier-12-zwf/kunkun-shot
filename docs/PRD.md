# 困困截图工具 · 产品需求文档（PRD）

> 说明：本 PRD 由**现有代码与功能逆向倒推**而成（reverse-engineered），用于沉淀产品定义、对齐后续迭代。
> 产品代号 `kunkun-shot`，当前版本 `v0.2.0`，平台 macOS（Electron）。
> 文档基于实际实现盘点（IPC 通道、渲染模块、配置项），非凭空设想；标注「⚠️ 待完善 / 已知限制」处为真实现状。

---

## 1. 产品概述

**一句话定位**：一款仿 PixPin 的 macOS 本地截图工具，集「截图标注 + 贴图 + OCR + AI 问答/翻译 + 长截图 + 录屏 + 历史管理」于一体，主打**本地、快捷、AI 增强**。

**产品形态**：菜单栏常驻 App + 全局快捷键唤起 + 浮层交互（截图蒙版 / 贴图窗 / AI 面板 / 长截图条 / 录屏条）。

**核心差异点**：
- 截图链路里**原生集成大模型**（DeepSeek、MiniMax 与通用 OpenAI 兼容文本服务，可智能分流），截完即可问 AI、翻译、润色；
- **截图原位翻译**（识别每行文字+坐标，译文盖回原文位置，沉浸式翻译式体验）；
- **本地优先**：OCR 可走本地 tesseract，配置与历史存本地，隐私可控。

---

## 2. 目标与非目标

**目标**
- 覆盖日常截图全链路：截 → 标注 → 用（复制/保存/贴图/OCR/AI）；
- 让「截图 + AI」一步到位，减少在多个 App 间来回切换；
- 快捷键驱动、浮层交互，尽量不打断用户心流。

**非目标（当前阶段不做）**
- 跨平台（当前仅 macOS）；
- 云端同步 / 多端协作；
- 团队/企业级权限与审计。

---

## 3. 目标用户与典型场景

**用户**：开发者、产品/运营、学生、内容创作者等高频截图人群（个人使用为主）。

**典型场景**
1. 截一段报错/代码 → 直接「问 AI」拿解法；
2. 截外文资料 → 「翻译」原位看译文；
3. 截图中文字 → 「OCR」提取可复制文本；
4. 截一张图钉在屏幕上对照操作（贴图）；
5. 截超出屏幕的长页面（长截图滚动拼接）；
6. 录一段操作演示导出 GIF；
7. 回看/导出历史截图。

## 4. 功能需求

### 4.1 截图捕获（Capture）
- **区域截图**：全局快捷键 `Cmd+Shift+A` 唤起全屏蒙版 → 框选区域；支持选区调整、十字辅助线。
- **全屏截图** / **窗口截图** / **定时截图**（延时后自动截）。
- 多显示器支持（按显示器创建蒙版）。
- 截图后行为可配置：是否自动复制、是否自动贴图、是否自动存历史。
- 通道：`CAPTURE_TRIGGER / CAPTURE_FULLSCREEN(_NOW) / CAPTURE_REGION / CAPTURE_WINDOW / CAPTURE_TIMED`。

### 4.2 标注编辑（Overlay 编辑器）
- 选区工具栏提供绘图标注：矩形/箭头/画笔/文字/马赛克等形状（shapes），颜色选择，撤销/重做。
- 选区可移动、可调整；`V` 切换选择工具，`Enter` 执行默认动作，`Esc` 取消。
- 工具栏动作：OCR / 问AI / 翻译 / 贴图 / 保存 / 复制 / 关闭。

### 4.3 贴图（Pin）
- 把当前选区「贴」到屏幕上方常驻浮窗，便于对照；可拖动、可缩放。
- 支持从剪贴板贴图：`Cmd+Shift+P`。
- 通道：`PIN_CREATE`。

### 4.4 OCR 文字识别
- 两种引擎（设置可选）：
  - **本地模式**（默认）：tesseract.js，语言 `chi_sim+eng`，**真离线免费**（语言包随包内置 `tessdata/`，启动前预填进 tesseract 缓存，规避 Electron 下误走联网分支导致的卡死）；
  - **大模型模式**：走视觉大模型识别（更准，联网，用当前 AI 供应商的 visionModel）。
- 输出可复制文本；可一键转「翻译 / 润色 / 问 AI」。
- 通道：`OCR_RUN`；另有 `OCR_BOXES`（macOS Vision，输出每行文字+精确坐标，供原位翻译）。

### 4.5 AI 能力（问答 / 翻译 / 润色）
- **截图问 AI**：把选区图发给视觉模型，针对报错/题目/内容给出解释与解法（默认提示词可配）。
- **翻译**、**润色**：基于 OCR 文本或选区图。
- **提供商模式**：DeepSeek（文本任务；截图先走本地 OCR）、MiniMax（`MiniMax-M3`，支持直接看图），以及通用 OpenAI 兼容文本服务（硅基流动 / 通义千问 / Kimi / 自定义端点）。
  - 模式：`deepseek` / `minimax` / `openai` / `auto`。智能分流时，图片优先走已配置的 MiniMax；文本优先走已配置的 OpenAI 兼容服务，否则回退到 DeepSeek。
- 流式输出；思考过程控制（翻译/OCR 只出结果，问答可展示思考）。
- 通道：`DEEPSEEK_ASK_IMAGE / DEEPSEEK_CHAT / DEEPSEEK_STREAM / DEEPSEEK_TEST`。

### 4.6 截图原位翻译（沉浸式）⚠️ 持续打磨中
- 选区点「翻译」→ 系统 Vision OCR 识别每行文字+坐标 → 大模型逐行翻译 → **译文按坐标盖回每行原文位置**。
- **目标语言可选（已实现）**：截图工具栏右侧下拉切换，支持中/英/日/韩/法/德/西/俄 共 8 种，默认中文；选择即写入 `translate.target` 配置。
- **保存/复制含译文（已实现）**：导出图（`composeImage`）会把译文层合成进 canvas，保存与复制得到的图即带覆盖译文，不再只是屏幕显示层。
- 已知点：大留白/带固定水印的页面，坐标对齐受限。

### 4.7 长截图（滚动拼接）⚠️ 已知限制
- `Cmd+Shift+L` 唤起 → 框定区域 → 用户匀速下滚 → 自动逐帧抓取并按重叠拼接成长图。
- 拼接策略：每 ~0.5s 抓帧，比对上下帧重叠区，只接「新出现」的部分；**仅在有内容的行上判定重叠**，避开滚动条与纯空白，避免错位/重复。
- 已知限制：**内容仍在变化（streaming）/ 来回滚 / 页面带固定水印（如飞书）** 这类场景，像素拼接天然不可靠。

### 4.8 录屏（Recording）
- `Cmd+Shift+R` 录制屏幕，导出 GIF 或视频；可配 fps（默认 12）与是否转 GIF。
- 通道：`RECORD_SAVE`。

### 4.9 历史记录（History）
- 列表/查看/删除/导出/清空；**仅手动保存的截图入库**（可开「自动保存」开关，默认关）。
- 历史按日期分组、旧日期默认折叠。
- 通道：`HISTORY_LIST/GET/DELETE/EXPORT/CLEAR/CHANGED`。

### 4.10 主界面与快捷入口
- **菜单栏托盘**常驻，**Popover** 快捷面板（`POPOVER_TOGGLE`）。
- **主窗口**含截图页 / 历史 / AI 工作台（三栏可折叠）。
- 剪贴板集成：写图/写文/读图（`CLIPBOARD_*`）；保存到本地、可选保存目录（`CHOOSE_SAVE_DIR`）。

## 5. 配置 / 设置需求

| 分类 | 配置项 | 默认值 |
|---|---|---|
| 快捷键 | 截图 / 贴剪贴板 / 录屏 / 长截图 / OCR | `Cmd+Shift+A / P / R / L / O` |
| AI | 供应商 provider | `deepseek`（可 `minimax` / `openai` / `auto`） |
| DeepSeek | baseUrl / 文本模型 / 视觉模型 / 各提示词 | `api.deepseek.com`、`v4-flash` / `v4-pro` |
| MiniMax | baseUrl / 文本 / 视觉模型 / apiKey | `api.minimaxi.com`、`MiniMax-M3` |
| OpenAI 兼容 | preset / baseUrl / 文本模型 / apiKey | `siliconflow`、`deepseek-ai/DeepSeek-V3`；亦可选通义千问、Kimi 或自定义端点 |
| OCR | 引擎(local/model) / 语言 | `local`、`chi_sim+eng` |
| 原位翻译 | 目标语言 `translate.target`（中/英/日/韩/法/德/西/俄） | `中文` |
| 截图 | 截后复制 / 自动贴图 / 自动存历史 | 均 `false` |
| 录屏 | fps / 转 GIF | `12` / `true` |
| 通用 | 开机自启 / 保存目录 / 主题 | `false` / 空 / `light` |

## 6. 非功能需求

- **平台**：macOS（darwin）；Electron 桌面应用。
- **隐私/本地优先**：OCR 可全本地；配置与历史存用户目录；API Key 仅本地保存。
- **权限**：录屏/长截图需「屏幕录制」权限（TCC）。当前公开源码构建未签名、未公证，重新打包后 macOS 可能要求重新授权；正式分发前需使用有效的 Apple Developer ID 完成签名与公证。
- **性能**：截图蒙版即开即用；长截图抓帧 ~0.5s/帧；原位翻译首次含 swift 编译，后续 OCR ~1.5–2s。
- **交互**：全局快捷键唤起；浮层不抢焦不打断；所有浮窗可拖动/可缩放（贴图等）。

## 7. 技术架构（简）

- **主进程**：`main.js`（窗口/快捷键/截图/AI/OCR/历史调度）、`windows.js`（各窗口）、`config.js`、`deepseek.js`（AI 调用：streamChat/completeText/imageMessage/stripThink）、`ocr.js`（tesseract）、`ocr-boxes.js`（macOS Vision 出坐标）、`media.js`（录屏）、`history.js`。
- **渲染层**：`overlay`（截图标注+AI 面板+原位翻译）、`pin`、`longshot`、`recorder`、`ai`、`settings`、`popover`、`main`。
- **桥接**：`preload` 注入 `window.kkapi`（contextBridge），渲染层禁止直接 require；所有窗口启用 `contextIsolation:true`、`nodeIntegration:false` 与 `sandbox:true`。
- **通道**：`src/shared/channels.js` 统一定义（当前 53 个 IPC 通道，即功能地图）。

## 8. 已知限制与后续迭代

**已知限制（诚实标注）**
1. 长截图对「内容仍在变化 / 来回滚动 / 带固定水印（飞书等）」的页面拼接不可靠——像素级拼接的天生短板。滚太快且无法判定重叠时，现已改为**暂停拼接 + 红色提示**（不再静默整帧硬接出错位长图）。
2. 原位翻译在大留白/复杂排版下坐标对齐受限。（保存/复制不含译文的限制已解除，见 §4.6。）

**后续迭代候选**
- 原位翻译：~~目标语言选择器~~（已做）、~~把译文合成进导出图~~（已做）、对齐精修；
- 长截图：针对固定水印的专门处理、滚动引导/防错位提示；
- 跨平台（Windows）、云同步（远期）。
