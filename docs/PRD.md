# 困困截图工具 · 产品需求文档（PRD）

> 说明：本 PRD 由**现有代码与功能逆向倒推**而成（reverse-engineered），用于沉淀产品定义、对齐后续迭代。
> 产品代号 `kunkun-shot`，当前版本 `v0.2.0`，平台 macOS（Electron）。
> 文档基于实际实现盘点（IPC 通道、渲染模块、配置项），非凭空设想；标注「⚠️ 待完善 / 已知限制」处为真实现状。

---

## 1. 产品概述

**一句话定位**：一款对标 PixPin 工作流的 macOS 本地截图工具，集「截图标注 + 贴图与工作区 + OCR + AI 问答/翻译/表格/公式识别 + 长截图 + 可选音频录屏 + 历史管理」于一体，主打**本地、快捷、AI 增强**。

**产品形态**：菜单栏常驻 App + 全局快捷键唤起 + 浮层交互（截图蒙版 / 贴图窗 / AI 面板 / 长截图条 / 录屏条）。

**核心差异点**：
- 截图链路里**原生集成大模型**（DeepSeek、MiniMax 与通用 OpenAI 兼容文本服务），截完即可问 AI、翻译、润色、识别表格或公式；
- **截图原位翻译**（识别每行文字+坐标，译文盖回原文位置，沉浸式翻译式体验）；
- **本地优先**：OCR 可走本地 Tesseract，配置、历史与贴图工作区存本地，隐私可控；
- **可自动化调用**：启动参数可直接进入区域/全屏/窗口/OCR/长截图/录屏流程，但仍保留 UI 与 macOS 权限边界。

---

## 2. 目标与非目标

**目标**
- 覆盖日常截图全链路：截 → 标注 → 用（复制/保存/贴图/OCR/AI）；
- 让「截图 + AI」一步到位，减少在多个 App 间来回切换；
- 快捷键驱动、浮层交互，尽量不打断用户心流。

**非目标（当前阶段不做）**
- 跨平台（当前仅 macOS）；
- 云端同步 / 多端协作；
- 团队/企业级权限与审计。

---

## 3. 目标用户与典型场景

**用户**：开发者、产品/运营、学生、内容创作者等高频截图人群（个人使用为主）。

**典型场景**
1. 截一段报错/代码 → 直接「问 AI」拿解法；
2. 截外文资料 → 「翻译」原位看译文；
3. 截图中文字 → 「OCR」提取可复制文本；
4. 截一张图钉在屏幕上对照操作（贴图）；
5. 截超出屏幕的长页面（长截图滚动拼接）；
6. 录一段操作演示导出 GIF；
7. 回看/导出历史截图。
8. 截取表格转为 Markdown/CSV，或截取数学公式转为 LaTeX。
9. 使用脚本或启动器参数打开指定截图流程。

## 4. 功能需求

### 4.1 截图捕获（Capture）
- **区域截图**：全局快捷键 `Cmd+Shift+A` 唤起全屏蒙版 → 框选区域；支持选区调整、十字辅助线。
- **全屏截图** / **窗口截图** / **定时截图**（延时后自动截）。
- 多显示器支持（按显示器创建蒙版）。
- 截图后行为可配置：是否自动复制、是否自动贴图、是否自动存历史。
- 通道：`CAPTURE_TRIGGER / CAPTURE_FULLSCREEN(_NOW) / CAPTURE_REGION / CAPTURE_WINDOW / CAPTURE_TIMED`。

### 4.2 标注编辑（Overlay 编辑器）
- 选区工具栏提供矩形、椭圆、箭头、直线、画笔、荧光笔、折线、文字、马赛克和序号标注，并支持颜色、撤销/重做。
- 选区可移动、可调整；`V` 切换选择工具，`Enter` 执行默认动作，`Esc` 取消。
- 工具栏动作：OCR / 问AI / 翻译 / 贴图 / 保存 / 复制 / 关闭。

### 4.3 贴图（Pin）
- 把当前选区「贴」到屏幕上方常驻浮窗，便于对照；支持拖动、缩放、透明度、置顶、锁定、鼠标穿透、缩略、标题和恢复最近关闭项。
- 剪贴板入口 `Cmd+Shift+P` 可贴图片、文字、颜色或 Finder 文件。
- 图片贴图可使用画笔、直线、箭头、矩形、椭圆、文字和橡皮，并支持撤销/重做/清空。标注会合成到复制、保存、OCR、AI 和拖出文件的实际内容中。
- 正常退出时会将打开的贴图与当前窗口状态原子持久化到用户数据目录，下次启动恢复；图片内容使用哈希校验，不信任同长度的损坏文件。

### 4.4 OCR 文字识别
- 两种引擎（设置可选）：
  - **本地模式**（默认）：tesseract.js，语言 `chi_sim+eng`，**真离线免费**（语言包随包内置 `tessdata/`，启动前预填进 tesseract 缓存，规避 Electron 下误走联网分支导致的卡死）；
  - **大模型模式**：走视觉大模型识别（更准，联网，用当前 AI 供应商的 visionModel）。
- 输出可复制文本；可一键转「翻译 / 润色 / 问 AI」。
- 通道：`OCR_RUN`；另有 `OCR_BOXES`（macOS Vision，输出每行文字+精确坐标，供原位翻译）。

### 4.5 AI 能力（问答 / 翻译 / 润色 / 表格 / 公式）
- **截图问 AI**：把选区图发给视觉模型，针对报错/题目/内容给出解释与解法（默认提示词可配）。
- **翻译**、**润色**：基于 OCR 文本或选区图。
- **提供商模式**：DeepSeek（文本任务；截图先走本地 OCR）、MiniMax（`MiniMax-M3`，支持直接看图），以及通用 OpenAI 兼容文本服务（硅基流动 / 通义千问 / Kimi / 自定义端点）。
  - 模式：`deepseek` / `minimax` / `openai` / `auto`。`auto` 是失败关闭的固定路由：纯文本任务只发 DeepSeek，看图任务只发 MiniMax，必须同时配置两者。不会用其他服务商的残留 Key 静默改投端点。
- 流式输出；思考过程控制（翻译/OCR 只出结果，问答可展示思考）。
- **AI 表格识别**：优先输出 GitHub Flavored Markdown，只在 Markdown 无法忠实表达时输出 CSV 代码块。
- **AI 公式识别**：输出 LaTeX，不解题或自行补全缺失符号。
- 表格/公式的任务模式由渲染层选择，固定提示词保留在主进程。视觉提供方直接看图；纯文本提供方只接收本地 OCR 结果，因缺少单元格坐标而可能无法可靠恢复复杂表格。

### 4.6 截图原位翻译（沉浸式）⚠️ 持续打磨中
- 选区点「翻译」→ 系统 Vision OCR 识别每行文字+坐标 → 大模型逐行翻译 → **译文按坐标盖回每行原文位置**。
- **目标语言可选（已实现）**：截图工具栏右侧下拉切换，支持中/英/日/韩/法/德/西/俄 共 8 种，默认中文；选择即写入 `translate.target` 配置。
- **保存/复制含译文（已实现）**：导出图（`composeImage`）会把译文层合成进 canvas，保存与复制得到的图即带覆盖译文，不再只是屏幕显示层。
- 已知点：大留白/带固定水印的页面，坐标对齐受限。

### 4.7 长截图（滚动拼接）⚠️ 已知限制
- `Cmd+Shift+L` 唤起 → 框定区域 → 用户匀速下滚 → 自动逐帧抓取并按重叠拼接成长图。
- 拼接策略：自适应抓帧节奏，比对上下帧重叠区并只接「新出现」的部分；使用方向/任务令牌和失败上限阻断过期帧与无界重试。
- 已知限制：**内容仍在变化（streaming）/ 来回滚 / 页面带固定水印（如飞书）** 这类场景，像素拼接天然不可靠。

### 4.8 录屏（Recording）
- `Cmd+Shift+R` 录制选定区域，可保存 WebM，或通过 FFmpeg 转为 H.264 MP4/GIF；可配 fps（默认 12）与是否转 GIF。
- 支持暂停/继续、取消、剪辑、超限保护和保存失败后重试；时长以有效录制时间计算，不把暂停时间算入。
- 系统声音与麦克风可独立选择，默认都关闭；两者同时开启时混成一条录制音轨。已选音源权限被拒或实际不可用时明确失败，不静默退化成无声录屏。

### 4.9 历史记录（History）
- 列表/查看/搜索/筛选/复制/删除/批量删除/导出/清空。“自动保存到历史”默认关闭，但成功执行“保存”或“快速保存”时仍会在历史库另存一份私有副本。
- 清空历史只删除历史库的应用副本，不会删除用户另存到其他目录的文件。
- 历史按日期分组、旧日期默认折叠。
- 通道：`HISTORY_LIST/GET/DELETE/EXPORT/CLEAR/CHANGED`。

### 4.10 主界面与快捷入口
- **菜单栏托盘**常驻，**Popover** 快捷面板（`POPOVER_TOGGLE`）。
- **主窗口**含截图页 / 历史 / AI 工作台（三栏可折叠）。
- 剪贴板集成：写图/写文/读图（`CLIPBOARD_*`）；保存到本地、可选保存目录（`CHOOSE_SAVE_DIR`）。

### 4.11 图片导出与启动参数
- 截图可原子写入 PNG、JPEG、WebP、BMP、AVIF 或单页 PDF；快速保存、保存对话框默认格式和历史批量导出共用配置。编码失败不会把临时或半成品冒充为成功文件。
- `--capture=region|fullscreen|window|ocr|long|record` 可从首次或第二次启动进入对应权威流程；`--delay=1..300` 只允许区域或全屏。重复、未知、非整数或越界参数失败关闭。
- 启动参数不是无头文件导出 API；对应流程仍使用图形界面并受 macOS 权限约束。

## 6. 非功能需求

- **平台**：macOS（darwin）；Electron 桌面应用。
- **隐私/本地优先**：OCR 可全本地；配置、历史与贴图工作区存用户目录。API Key 只有在 Electron `safeStorage` 成功加密后才落盘；安全存储不可用或加密失败时明确拒绝保存。
- **权限**：截图/录屏/长截图需“屏幕录制”权限（TCC）；只在用户显式开启时请求系统音频录制或麦克风权限。
- **发布真实性**：`dist:mac:local` 是明确无签名/无公证的本地路径；`dist:mac:release` 是必须具备 Developer ID 与一套完整公证凭据的失败关闭流水线，会验证 Developer ID、Team ID、Hardened Runtime、Gatekeeper、stapled ticket、DMG/ZIP 完整性与 SHA-256。当前仓库没有凭据、公证记录或已验证正式产物，不声称已签名/已公证。
- **性能口径**：实际延迟取决于屏幕尺寸、显示器、OCR 语言、图像复杂度与 AI 服务；当前不承诺固定抓帧或 OCR 耗时。macOS Vision 帮助程序在打包前构建并随应用携带，不应把开发环境的现场 Swift 编译当作产品性能承诺。
- **交互**：全局快捷键、菜单栏和启动参数唤起；截图蒙版、贴图和录屏控制条按各自的交互契约管理焦点与窗口。

## 7. 技术架构（简）

- **主进程**：`main.js`（窗口/快捷键/截图/AI/OCR/历史调度）、`windows.js`（各窗口）、`config.js`、`deepseek.js`（AI 调用）、`ai-recognition.js`（AI 表格/公式任务边界）、`ocr.js`/`ocr-worker.js`（Tesseract）、`ocr-boxes.js`（macOS Vision 出坐标）、`image-export.js`、`media.js`、`history.js`、`pin-workspace-store.js`、`launch-actions.js`。
- **渲染层**：`overlay`（截图标注+AI 面板+原位翻译）、`pin`、`longshot`、`recorder`、`ai`、`settings`、`popover`、`main`。
- **桥接**：`preload` 注入 `window.kkapi`（contextBridge），渲染层禁止直接 require；所有窗口启用 `contextIsolation:true`、`nodeIntegration:false` 与 `sandbox:true`。
- **通道**：`src/shared/channels.js` 统一定义；渲染窗口只能通过 preload 白名单调用对应能力，不在文档中固化会随功能变化的通道数量。

## 8. 已知限制与后续迭代

**已知限制（诚实标注）**
1. 长截图对「内容仍在变化 / 来回滚动 / 带固定水印（飞书等）」的页面拼接不可靠——像素级拼接的天生短板。滚太快且无法判定重叠时，现已改为**暂停拼接 + 红色提示**（不再静默整帧硬接出错位长图）。
2. 原位翻译在大留白/复杂排版下坐标对齐受限。（保存/复制不含译文的限制已解除，见 §4.6。）
3. 系统声音、麦克风、多显示器/TCC、窗口截图、AVIF/PDF 的 Preview/Finder 兼容性、贴图工作区跨重启，以及实际 AI 凭据路由都需目标 macOS 真机验收；自动测试不能代替。
4. AI 表格/公式识别受截图清晰度和模型能力影响；纯文本提供方仅收到本地 OCR 文本，不保证复杂表格结构还原。
5. 仓库只提供正式签名/公证流水线；没有凭据和产物证据时，不得将流水线存在写成“已签名/已公证”。

**后续迭代候选**
- 原位翻译：~~目标语言选择器~~（已做）、~~把译文合成进导出图~~（已做）、对齐精修；
- 长截图：针对固定水印的专门处理、滚动引导/防错位提示；
- 跨平台（Windows）、云同步（远期）。
