# 困困截图工具使用指南

> 适用版本：`0.3.0`（macOS 预览版）
> 本指南按当前仓库代码与默认配置编写。当前重点支持 macOS，不承诺 Windows 或 Linux 可用。应用没有自动更新器；当前仓库也没有可据以证明公开产物已经完成 Apple Developer ID 签名与公证的记录。

困困截图工具是一款常驻 macOS 菜单栏的截图工具。它提供区域、窗口、全屏和延时截图，完整标注，图片/文字/颜色/文件贴图，本地 OCR，二维码与常见条码识别，可校正和重拼的长截图，区域录屏，以及可选的 AI 问图、翻译、表格和公式识别。

## 1. 五分钟快速上手

1. 将“困困截图工具.app”放入“应用程序”文件夹并启动。
2. 第一次截图时，按系统提示授予“屏幕录制”或“屏幕与系统录音”权限，然后从菜单栏图标中彻底退出并重新启动应用。
3. 按 `⌘ ⇧ A`，拖动鼠标框选区域。
4. 如有需要，在选区下方工具栏添加箭头、矩形、文字、马赛克等标注。
5. 工具栏一级动作从“翻译”“OCR”开始；可直接选择翻译、OCR、贴图或复制，其他识别与保存动作在“更多”中。
6. 按 `Enter` 执行默认复制，或点击所需动作完成。

如果只使用截图、标注、贴图和本地 OCR，不需要配置任何 AI API Key，也不需要把识别内容发送到互联网。

## 2. 安装、更新与首次启动

### 2.1 安装已打包应用

从可信来源取得 `.dmg`、`.zip` 或 `.app` 后：

1. 如果应用正在运行，右击菜单栏图标并选择“退出困困截图工具”。只关闭主窗口并不一定会退出菜单栏进程。
2. 打开 `.dmg` 或解压 `.zip`。
3. 将“困困截图工具.app”拖入 `/Applications`，即 Finder 的“应用程序”文件夹。
4. 从“应用程序”中启动它。

当前这台电脑上的安装位置是：

```text
/Applications/困困截图工具.app
```

本指南对应的源码发布版本为 `0.3.0`，应用标识为 `com.kunkun.shot`。

### 2.2 macOS 阻止打开时

当前项目不应被当作已经完成正式 Apple 公证的公开发行版。如果 macOS 阻止打开，而你能够确认应用来自自己构建或其他可信来源，可以：

1. 在 Finder 中右击应用，选择“打开”；或
2. 打开“系统设置 → 隐私与安全性”，在相应提示旁选择“仍要打开”。

不要为来源不明的应用绕过系统保护，也不要随意执行网上提供的全局 Gatekeeper 关闭命令。

### 2.3 从源码运行

开发运行需要 macOS、Node.js `22.12.0` 或更高版本、npm，以及首次安装依赖时的网络连接：

```bash
git clone https://github.com/duangjaiignacy-blip/kunkun-shot.git
cd kunkun-shot
npm ci
npm test
npm start
```

开发模式下，macOS 权限列表里可能显示的是 Electron 或启动它的终端，而不是“困困截图工具”。

### 2.4 手动更新

应用目前没有自动更新机制。更新步骤是：

1. 从菜单栏右键菜单彻底退出旧版本。
2. 备份重要历史或贴图工作区；数据目录见[第 17 节](#17-数据位置备份与隐私)。
3. 用可信的新 `.app` 替换 `/Applications/困困截图工具.app`。
4. 重新打开应用，检查截图、全局快捷键和菜单栏图标。
5. 如果系统再次询问权限，重新授权后彻底退出并启动一次。

不要用临时 ad-hoc 签名的包覆盖日常安装版本来期待保留原有 TCC 权限；项目的本机构建、正式发布和签名要求分别见 [MACOS_LOCAL_BUILD.md](MACOS_LOCAL_BUILD.md) 与 [MACOS_RELEASE.md](MACOS_RELEASE.md)。

## 3. macOS 权限

### 3.1 权限用途

| 权限 | 何时需要 | 不授权时的表现 |
| --- | --- | --- |
| 屏幕录制 / 屏幕与系统录音 | 区域、窗口、全屏、延时截图，长截图和录屏 | 可能只得到壁纸、黑屏、空白画面，或捕获直接失败 |
| 麦克风 | 只在“设置 → 录屏 → 麦克风”开启后录屏 | 已明确要求麦克风时，录制会报错停止，不会悄悄导出无麦克风声音的视频 |
| 系统音频录制 | 只在“设置 → 录屏 → 系统声音”开启后录屏 | 已明确要求系统声音时，录制会报错停止，不会静默降级成无声视频 |
| 相机 | 只在录屏控制条开启镜头画中画后 | 镜头启动失败会明确提示；再次点击开始可改为纯屏幕录制。相机只提供画面，不采集相机麦克风 |
| 辅助功能 | 智能 UI 选区、全局划词翻译、录屏动作提示和成片画笔 | 无法读取可访问控件边界、复制当前选中文字或监听全局鼠标/按键；动作提示与依赖它的成片画笔不可用 |

不同 macOS 版本的权限名称可能略有差异。屏幕权限通常位于“系统设置 → 隐私与安全性 → 屏幕录制”，新版本也可能显示为“屏幕与系统录音”。相机、麦克风和辅助功能在同一“隐私与安全性”页面内。

### 3.2 正确授权流程

1. 先启动应用并实际触发一次对应功能，例如区域截图或带麦克风的录屏。
2. 在系统设置中为“困困截图工具”开启相应权限。
3. 从菜单栏右键菜单选择“退出困困截图工具”。
4. 重新启动应用，再次测试。

权限变化通常只有在应用进程完全重启后才生效。关闭主窗口不等于退出应用。

## 4. 主窗口与菜单栏

### 4.1 主窗口

主窗口左侧有四个页面：

| 页面 | 用途 |
| --- | --- |
| 快捷截图 | 启动区域、窗口、全屏、延时、长截图和录屏，查看最近 6 项，并切换“自动复制” |
| 历史记录 | 搜索、筛选、查看、复制、导出、OCR、翻译、发送 AI 或删除历史 |
| AI 工作台 | 选择历史图片后进行问答、OCR、翻译、总结、润色和后续对话 |
| 设置 | 配置启动行为、快捷键、截图、录屏、OCR、AI、存储与隐私 |

关闭“设置 → 通用 → 启动时打开主窗口”后，应用启动时只驻留菜单栏。需要主窗口时点击菜单栏图标，或从右键菜单选择“打开主窗口”。

### 4.2 左击菜单栏图标

左击图标会打开快捷面板，可直接执行：

- 区域截图、窗口截图、长截图、区域录屏和全屏截图；
- 查看最近一张截图；
- 对最近截图执行“问 AI”“OCR”或“翻译”；
- 开关“截图后自动复制”；
- 打开主窗口。

按 `Escape` 可关闭快捷面板。

### 4.3 右击菜单栏图标

右键菜单提供更完整的入口：

- 打开主窗口；
- 区域、全屏、窗口、OCR、长截图和区域录屏；
- 把剪贴板内容贴到屏幕；
- 恢复最近关闭的贴图；
- 将全部贴图切换为缩略图、取消全部缩略图、全部保存、全部关闭或全部销毁；
- 打开“LaTeX 公式贴图”编辑器；
- 划词翻译；
- 打开设置；
- 打开数据文件夹（历史/配置）；
- 退出应用。

“全部关闭”会按最近关闭贴图的规则处理；“全部销毁”不会把销毁项放入最近关闭栈，适合确认不再需要恢复时使用。

## 6. 截图：区域、窗口、全屏与延时

### 6.1 区域截图

1. 按 `⌘ ⇧ A`，或从主窗口/菜单栏选择“区域截图”。
2. 在想截取内容所在的显示器上按住鼠标拖动。
3. 拖动八个控制点调整选区；拖动选区内部可整体移动。
4. 使用工具栏标注；一级动作最前面是“翻译”和“OCR”，也可直接贴图或复制，其他识别与保存动作在“更多”中。
5. 点击“复制”或按 `Enter` 完成默认动作。

多显示器会分别显示捕获层。请直接在目标显示器上开始拖选。

### 6.2 窗口截图

1. 从主窗口、菜单栏面板或右键菜单选择“窗口截图”。
2. macOS 会进入原生交互式窗口选择。
3. 点击目标窗口；取消系统选择则不会生成截图。
4. 成功捕获后会进入与区域截图相同的统一编辑器。

窗口捕获当前依赖 macOS 原生 `screencapture` 流程，因此属于 macOS 专用能力。

### 6.3 全屏截图

1. 从主窗口或菜单栏选择“全屏截图”。
2. 应用捕获当前目标显示器，并以整屏为初始选区打开编辑器。
3. 可以继续缩小选区、添加标注，再复制、保存或贴图。

### 6.4 延时截图

主窗口的“延时截图”提供 `3 秒`、`5 秒`、`10 秒` 和自定义倒计时：

1. 选择预设，或输入 `1–300` 的整数秒数并按 `Enter`。
2. 在倒计时内展开想捕获的菜单、提示或悬停状态。
3. 倒计时结束后进入区域截图。
4. 倒计时期间再次点击同一延时按钮可取消。

倒计时由主进程继续执行；即使切换主窗口页面也不会自动取消。通过启动参数还可以对全屏截图设置延时，见[第 16 节](#16-启动参数与自动化入口)。

## 7. 精细选区、历史选区、取色与二维码

### 7.1 精细调整选区

- 初次框选时按住 `Shift`，可锁定为正方形。
- 拖动选区内部可移动，拖动八个控制点可缩放。
- 方向键每次移动 1 个界面像素。
- `Shift` + 方向键从对应边缘向内收缩；`⌘` + 方向键从对应边缘向外扩展。
- 展开“更多”可直接输入宽、高；这里显示和输入的是最终截图的原始像素尺寸，在 Retina 屏幕上不等同于界面点数。
- 常用尺寸可一键选择 `640 × 480`、`1280 × 720`、`1920 × 1080` 或 `1080 × 1080`。
- 比例提供“自由”“1:1”“4:3”“16:9”。选择固定比例时会按当前选区就近调整，随后拖动控制点也会保持该比例；“比例锁定”按钮可开启/解除当前预设，处于“自由”时开启则默认使用 1:1。
- “圆角截图”会把圆角应用到最终复制、保存或贴图结果。
- “边框/阴影”按钮按“无 → 边框 → 阴影”循环，效果同样会进入最终合成结果。

### 7.2 智能 UI 选区

在更多选区选项中启用“智能 UI 选区”后，应用会尝试读取鼠标下方的 macOS 可访问控件边界。它需要“辅助功能”权限，并且效果取决于目标应用是否公开了可访问性信息；画布、游戏、远程桌面等内容可能无法提供准确边界。

### 7.3 最近选区与历史图片

- 按 `R` 循环载入最近使用过的选区，按 `Shift+R` 反向循环。
- 最多保留 10 个选区；只有成功完成复制、保存、贴图等动作后才记录。
- 按 `<` 或 `>` 可在截图编辑器里浏览历史图片，再对历史内容重新框选和处理。

### 7.4 取色

截图界面的放大镜会显示鼠标附近像素和颜色值：

1. 把指针移到目标像素。
2. 默认按 `C`，复制 `RGB` 值。
3. 按住 `Shift` 时会显示并复制 `HEX` 值。

如果在设置中更改了“截图 · 取色”单键，请使用修改后的按键。

### 7.5 二维码与条码

“更多”中的“条码结果”始终可用，不必等到识别成功才出现。打开后会明确显示正在扫描、没有结果、失败或已识别等状态，并可手动重试。识别直接读取当前选区对应的屏幕原图像素，不会让后加标注遮住码；流程会先快速扫描，必要时再用原分辨率复扫，以免缩放漏掉细小条纹或二维码模块。

- 可以查看并复制全部结果；
- 如果第一项是 `http://` 或 `https://` 链接，可以从结果面板打开；
- 优先使用系统浏览器支持的条码检测能力，并带二维码后备识别；实际可识别格式取决于当前运行环境；
- 很小、模糊、倾斜、低对比或画面本身损坏的码仍可能失败，建议只框住清晰原码后重试。

## 8. 截图标注与撤销重做

### 8.1 标注工具

| 工具 | 用途与操作 |
| --- | --- |
| 选择/移动 | 选择已有标注，移动、缩放或重新编辑；默认键 `V` |
| 矩形 | 拖出矩形框 |
| 椭圆 | 拖出圆或椭圆 |
| 箭头 | 从起点拖到终点 |
| 直线 | 绘制无箭头直线 |
| 画笔 | 自由手绘 |
| 荧光笔 | 绘制半透明强调线 |
| 折线 | 逐点点击；双击或按 `Enter` 完成，`Escape` 取消 |
| 文字 | 点击位置后输入；`Enter` 提交，`Shift+Enter` 换行 |
| 马赛克 | 涂抹遮挡敏感区域 |
| 模糊 | 用真实高斯模糊笔刷涂抹区域，适合柔化敏感内容 |
| 椭圆聚光灯 | 拖出椭圆，保留椭圆内内容并压暗外围，突出关注区域 |
| 放大镜 | 拖出可移动、可缩放的镜片，可选 `1.25×`、`1.5×`、`2×`、`3×`、`4×`、`6×` 或 `8×`；镜片会进入最终导出，与跟随指针但不导出的取色放大镜不同 |
| 水印 | 输入一次文字并放置一枚半透明倾斜水印；每次操作只生成一个水印，不会自动平铺 |
| 序号 | 依次添加编号标记 |

工具栏提供红、橙、绿、蓝、黑、白六种颜色，以及 `2`、`4`、`7` 三档线宽。不同工具会使用其中适用的颜色与宽度设置。

### 8.2 修改、删除、撤销与重做

1. 切换到“选择/移动”，点击已有标注。
2. 拖动它或控制点进行调整；文字可再次进入编辑。
3. 按 `Delete` 或 `Backspace` 删除选中项。
4. 按 `⌘ Z` 撤销，按 `⌘ ⇧ Z` 或 `⌘ Y` 重做。

标注、原位翻译、圆角、边框和阴影会在输出时合成到结果里；它们不会修改屏幕上的原内容。可导出放大镜取样时会沿用已经应用的模糊/马赛克结果，不会透过遮挡恢复敏感像素。如果保存失败，编辑器会尽量保留当前选区和标注，便于修正路径后重试。

## 9. 复制、保存与导出格式

### 9.1 常用输出动作

选区准备好后，一级动作依次以“翻译”“OCR”开头，后面是“更多”、贴图、复制和取消。“更多”中包含问 AI、表格、公式、条码结果、文字润色、保存、快速保存及翻译目标语言。这样可直接启动高频翻译，同时仍可在同一层级选择 OCR；目标语言不占用一级工具栏宽度。

| 动作 | 结果 |
| --- | --- |
| 原位翻译 | 识别文字行、翻译后把译文覆盖回原位置，再随图片一起输出；目标语言在“更多”中设置 |
| OCR | 在选区内识别文字并显示结果 |
| 贴图 | 把当前合成结果创建为悬浮图片贴图 |
| 复制 | 将当前选区与全部可见效果合成为图片写入系统剪贴板；普通截图按 `Enter` 默认执行此动作 |
| 保存 | 打开保存对话框，可选择路径和支持的格式 |
| 快速保存 | 按设置中的默认格式直接存到“截图保存目录”；目录留空时使用系统“图片”目录 |
| 问 AI | 打开 AI 面板处理当前选区 |
| 表格识别 | 识别为可编辑二维表，并可安全复制为 CSV、TSV 或 GitHub Flavored Markdown |
| 公式识别 | 输出 LaTeX |

开启“截图后自动复制”后，除显式“复制”外的静态截图完成动作也会附带复制；开启“截图后自动贴图”后，会附带创建贴图。

### 9.2 支持格式

| 格式 | 特点 | 质量参数 |
| --- | --- | --- |
| PNG | 无损，支持透明；默认格式 | 不使用 |
| JPEG | 兼容性好、体积较小，不支持透明 | `1–100` |
| WebP | 压缩率较高 | `1–100` |
| BMP | 无损、文件较大 | 不使用 |
| AVIF | 更高压缩率，但旧软件兼容性可能有限 | `1–100` |
| PDF | 将当前图片写成单页 PDF | `1–100` |

“设置 → 截图 → 默认导出格式”会影响快速保存、保存对话框的默认格式和历史批量导出。质量默认 `90`；数值越高通常画质越好、文件越大。

### 9.3 截图与录屏文件名模板

“设置”中可以分别配置截图和录屏文件名模板。默认值是 `困困截图-{timestamp}` 与 `困困录屏-{timestamp}`，支持以下令牌：

| 令牌 | 生成内容 |
| --- | --- |
| `{datetime}` | 本地日期和时间，例如 `2026-09-03_14-08-05` |
| `{date}` | 本地日期，例如 `2026-09-03` |
| `{time}` | 本地时间，例如 `14-08-05` |
| `{timestamp}` | 毫秒级 Unix 时间戳 |
| `{type}` | 内容类型，例如区域截图、录屏或历史 PDF 对应的内部类型名 |
| `{index}` | 当前批次中的顺序号；单文件从 `1` 开始 |
| `{width}`、`{height}` | 最终文件的实际像素宽、高 |

模板只写文件名主体，不要加入扩展名或目录分隔符；应用会按选择的格式添加扩展名，并在同名时追加 `-2`、`-3` 等编号，避免无提示覆盖。包含路径分隔符或文件系统非法字符、模板过长，或没有可用文件名内容时，设置会拒绝保存。

### 9.4 输出与历史记录的关系

- “自动保存到历史”默认关闭。
- 即使该开关关闭，成功执行“保存”或“快速保存”仍会在应用的私有历史库中另存一份。
- 其他截图动作只有在“自动保存到历史”开启时才会自动生成历史项。
- 清空应用历史不会删除你通过“保存”或“导出”放到其他目录的文件。

## 10. 贴图

### 10.1 创建贴图

可以在截图编辑器中点击“贴图”，也可以按 `⌘ ⇧ P` 贴出剪贴板内容。剪贴板识别优先级是：

1. 图片；
2. Finder 复制的文件 URL；
3. 文字或颜色。

当剪贴板同时包含图片和文字表示时，图片优先。颜色支持 `#RGB`、`#RRGGBB`、`rgb(...)` 和 `rgba(...)` 的前三个通道，并会规范成大写 HEX。Finder 文件必须是真实文件；文件夹不会创建文件贴图。

从截图编辑器创建图片贴图时，应用会先等待屏幕底图解码完成。贴图窗口收到图片后也会先解码验证再提交显示；较旧的异步加载结果不能覆盖后来载入的图片。替换图片期间会保留上一张已成功显示的画面，失败时会显示“贴图显示失败”和“重试显示”，不会悄悄变成空白。若屏幕原始捕获本身因权限或 DRM 是黑色，这仍需要按[故障排查](#189-贴图没有出现显示空白或无法点击)处理。

| 贴图类型 | 主要行为 |
| --- | --- |
| 图片 | 缩放、透明度、标注、复制、保存、OCR、AI、选择文字和拖出合成图片 |
| 文字 | 悬浮显示文字；复制时写回文字 |
| 颜色 | 显示色块与标准化色值；复制时写回色值 |
| Finder 文件 | 显示文件信息；点击可打开文件，复制时写回文件路径 |

### 10.2 图片贴图操作

- 拖动窗口移动贴图；锁定后不能移动、缩放或调整透明度。
- `+`/`=`、`-`、`0` 分别放大、缩小和恢复原始比例。
- 普通滚轮调整透明度；触控板捏合调整缩放。
- `T` 切换始终置顶，`L` 切换锁定，`R` 切换缩略图。
- 双击图片关闭贴图。
- 按 `F2` 编辑标题。
- 按住 `⌘` 拖动图片，可以把当前合成内容拖到 Finder 或支持拖放的应用。
- 右击图片可打开裁剪、旋转、翻转、分组及其他操作。

### 10.3 裁剪、旋转与翻转

在图片贴图上右击，选择“裁剪 / 旋转 / 翻转”中的操作：

- “裁剪图片…”进入裁剪层，拖出要保留的范围后应用；
- 可顺时针或逆时针旋转 `90°`；
- 可水平翻转或垂直翻转。

变换以当前合成画面为新底图：已有标注会被烘焙进图片，成功后旧标注不再保持为单独可编辑对象。若准备继续编辑标注，通常应先裁剪、旋转或翻转，再开始标注。

### 10.4 图片贴图标注

图片贴图提供：画笔、直线、箭头、矩形、椭圆、文字和橡皮擦，并带颜色选择、撤销、重做和清空。

标注以贴图原图为基础保存，不会反向改写最初的截图文件；但“复制”“保存”“OCR”“问 AI”和拖出文件都会使用当前已经合成标注的画面。同步或保存标注失败时，应用会阻止静默关闭，避免误丢正在编辑的内容。

### 10.5 贴图分组

在任一图片贴图上右击，可执行：

- “将当前所有贴图分组”：至少需要两个贴图；当前所有已打开贴图会加入同一组；
- 拖动组内任一成员：其他成员按相同位移一起移动；
- “折叠同组贴图”：保留当前贴图作为可见锚点并隐藏其余成员；再次选择可展开；
- “将此贴图移出分组”：解除当前贴图与该组的关系；剩余成员少于两个时自动解组。

当前分组入口针对“所有已打开贴图”，还没有任意框选部分贴图、嵌套分组或同时维护多个自选组的完整编组界面。

### 10.6 离线 LaTeX 公式贴图

右击菜单栏图标，选择“LaTeX 公式贴图…”：

1. 输入 KaTeX 兼容的 LaTeX 公式，或编辑默认示例；
2. 选择 `14–72` 的字号、文字颜色，以及透明、白色、暖白或深色背景；
3. 查看本地实时预览；
4. 点击“生成并贴到屏幕”，或按 `⌘ Enter`，在指针附近创建清晰的双倍像素 PNG 贴图。

公式渲染使用应用内置 KaTeX，不联网，也不上传公式内容。它支持 KaTeX 可识别的语法，不等于支持完整 TeX/LaTeX 发行版及任意宏包。这个入口用于手工输入并离线渲染；截图工具栏中的“公式识别”则是从图片识别 LaTeX 的 AI 功能，可能联网。

### 10.7 选择图片中的文字

1. 在图片贴图中按 `S` 进入“选择文字”。
2. 应用使用 macOS Vision 在本机识别文字行与位置。
3. 点击某一文字行即可复制。
4. 再按 `S` 或 `Escape` 退出。

这条流程是本地识别，但识别质量仍受清晰度、字体和版面影响。

### 10.8 鼠标穿透

按 `P` 后，鼠标事件会穿过贴图传给下方窗口。因为此时无法直接点击贴图，恢复时请按固定救援键 `⌘ ⌥ P`，它会取消所有贴图的穿透状态。

鼠标穿透不会写入跨重启工作区；重启后贴图不会保持不可点击状态。

### 10.9 关闭、恢复与跨重启工作区

- 手动关闭的贴图会进入“最近关闭”栈，当前会话最多保留 10 个；按 `⌘ 3` 逐个恢复。
- 最近关闭栈只保证当前应用会话内有效，不应把它当作跨重启历史。
- 正常退出应用时，仍打开的贴图会保存位置、大小、透明度、锁定、置顶、标题和内容，并在下一次正常启动时恢复。
- “全部销毁”不会进入最近关闭栈，也不用于之后恢复。

### 10.10 批量管理

菜单栏右键的贴图管理可以：全部缩略、取消全部缩略、全部保存、全部关闭或全部销毁。“全部保存”会把图片贴图保存为 PNG，把文字和颜色贴图保存为 TXT；当前批量保存不包含 Finder 文件贴图。

## 11. OCR、AI 与联网数据边界

### 11.1 OCR 的两条路径

| 路径 | 是否联网 | 说明 |
| --- | --- | --- |
| 截图工具栏的 OCR | 否 | 固定使用应用内置 Tesseract.js 与本地语言数据 |
| 贴图选择文字、原位翻译的文字框检测 | 否 | 使用 macOS Vision 在本机识别文字行位置 |
| AI 工作台/独立 OCR 面板选择“本地引擎” | 否 | 使用内置 Tesseract.js |
| AI 工作台/独立 OCR 面板选择“大模型模式” | 是 | 按当前 AI 提供方规则发送图片或本地 OCR 文字 |

设置中的本地 OCR 提供 9 种单语言：简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语和葡萄牙语。除英语外，其余 8 种都另有“该语言 + English”的组合选项，例如“日语 + English”或“繁体中文 + English”。语言数据随应用提供；缺失时会明确失败，不会从 CDN 自动下载。

注意：“设置 → OCR → 大模型模式”用于专门的 AI/OCR 面板流程，不会把截图工具栏内的即时 OCR 悄悄改成云端识别。

### 11.2 AI 工作台

1. 先让图片进入历史记录，例如执行一次“保存”或开启自动历史。
2. 打开主窗口的“AI 工作台”。
3. 从左侧选择一张历史图片；录屏条目不会作为工作台图片。
4. 可直接问图，或先 OCR，再编辑/复制文字并执行翻译、总结、润色。
5. 可以继续追问；切换图片会结束当前图片的对话状态和进行中的流式请求。

截图编辑器、历史详情和图片贴图也可以打开独立 AI 面板。贴图发起 OCR/AI 时使用包含当前标注的合成图片。

### 11.3 提供方与实际发送内容

| 当前提供方 | 文字任务 | 图片任务 |
| --- | --- | --- |
| DeepSeek | 发送文字到配置的 DeepSeek 端点 | 先在本地 OCR，只发送识别文字；DeepSeek 当前不直接接收截图 |
| MiniMax | 发送文字到 MiniMax | 将用户主动选择的截图发送给支持看图的 MiniMax 模型 |
| 更多服务商 | 发送到硅基流动、通义千问、Kimi 或自定义 OpenAI 兼容端点 | 先在本地 OCR，只把识别文字发送到所选端点 |
| 智能分流 | 固定只用 DeepSeek | 固定只用 MiniMax；两者必须分别配置，缺失时停止而不改投其他服务商 |

表格识别会解析模型返回的 GitHub Flavored Markdown 或 CSV；公式识别返回 LaTeX。纯文本提供方只能看到本地 OCR 后的文字，因此对复杂表格结构、公式排版和图形关系的还原通常弱于直接看图模型。

### 11.4 可编辑表格与安全导出

在截图编辑器选择“更多 → 表格识别”，或从相应 AI 图片入口启动表格任务。识别完成后：

1. 结果会解析成单元格表格，可逐格点击并修改；
2. 可切换查看模型返回的原始文本，便于核对解析；
3. 可把修改后的内容复制为 CSV、TSV 或 GitHub Flavored Markdown（GFM）。

CSV/TSV 会正确处理分隔符、引号和换行，并对以 `=`、`+`、`-`、`@` 开头（允许前导空格）的单元格加安全前缀，降低粘贴进电子表格时触发公式注入的风险。GFM 导出会转义反斜杠和竖线，并把单元格内换行转成 `<br>`。当前入口把结果复制到剪贴板，不是直接生成 `.csv` 文件；粘贴或另存后仍应核验敏感数据、公式和表格结构。

为防止异常结果拖垮界面，解析会限制原始字符数、行列数和单元格长度；超出范围会明确报错，不会无界生成表格。

### 11.5 翻译

- “原位翻译”先在本机用 Vision 找出文字行，再把识别文字发送给当前文本 AI 路由；不会把整张截图发送给纯文本提供方。译文覆盖回原位置，并进入最终复制、保存或贴图结果。
- “翻译”位于截图编辑器一级动作的第一位；目标语言在旁边的“更多”中选择，可选中文、英语、日语、韩语、法语、德语、西班牙语或俄语。
- “划词翻译”先模拟 `⌘ C` 读取当前选中文字，因此需要辅助功能权限；它会尽量保留并恢复原剪贴板，然后将选中文字发送给当前 AI 文本提供方，在指针附近显示结果。

### 11.6 哪些操作会联网

截图、标注、贴图、本地 OCR、Vision 文字框识别、历史管理本身不需要联网。以下操作会发起网络请求：

- 问 AI、AI OCR、翻译、总结、润色、表格识别和公式识别；
- 划词翻译；
- 测试 AI 连接；
- 为支持的 OpenAI 兼容服务刷新模型列表。

请求可能包含提示词、用户输入、截图、OCR 文字或选中文字，具体取决于上表的提供方路由。鉴权 Key 会随请求发送到你配置的服务端点。

API Key 只有在 Electron `safeStorage` 成功加密后才会写入本机配置；安全存储不可用或加密失败时保存会明确报错，不会降级成明文保存。请同时遵守所用服务商的隐私、数据保留与计费规则，不要把个人信息、商业秘密或第三方受限内容发送给不受信任的端点。

## 12. 长截图

长截图适合静态、连续滚动的网页、文档或列表。它会保留本次会话捕获的原始帧，因此自动拼接不理想时可以暂停、删帧重拼，而不必立刻从头再截。

### 12.1 捕获与完成

1. 从主窗口、菜单栏或全局快捷键 `⌘ ⇧ L` 启动长截图。
2. 像区域截图一样框出要拼接的内容区。
3. 在控制条中先选择“纵向”或“横向”；已有内容后不能切换方向。
4. 点击“开始”，再由你缓慢、稳定地滚动内容。当前版本不会代替你自动滚动目标页面。
5. 应用连续保存原始帧并匹配重叠区域；需要检查时点击“暂停”，之后可点“继续”。
6. 根据需要修正原始帧、固定区域和导出裁边。
7. 点击“完成”或按 `Enter`，选择保存位置。只有保存成功后才会复制结果并关闭；取消保存或保存失败会保留现场，可再次完成并重试。

### 12.2 原始帧、删帧重拼与撤销重做

- “片段”下拉列表按顺序列出本次保留的原始帧，可从中指定要删除的帧；
- 暂停后可删除误滚、重复或异常帧，应用会用剩余原始帧重新拼接；最后一帧不会被删除，相邻帧没有可靠且唯一的重叠时也会取消本次删除；
- 删除帧、修改固定顶/底区等校正操作支持撤销和重做；
- 某次重拼失败时会保留上一版可用拼接图和原始帧，不会用失败结果覆盖现场。

原始帧只保存在当前长截图窗口的内存工作区，并不是可跨关闭恢复的工程文件。关闭或取消窗口后，不能依靠历史记录继续编辑这些帧。

### 12.3 固定顶部/底部区域

网页固定导航栏、表头或底栏可能在每一帧重复出现。控制条提供以“捕获帧原始像素”为单位的固定顶部、固定底部高度：

1. 点击自动建议，让应用从稳定重复内容中估计顶/底高度；
2. 核对或手动修改数值；
3. 点击应用并重新拼接；
4. 需要时可撤销或重做这次调整。

自动建议只是辅助判断。视频、轮播、吸顶元素尺寸变化或内容相似度不足时，仍应人工确认。

### 12.4 导出裁边与失败后继续

顶部/底部裁剪滑块只裁最终导出结果，不会破坏保存的原始帧。它适合去掉首尾空白、重复边缘或不需要的浏览器区域。

抓帧连续失败、捕获宽度变化、显示缩放比例变化或等待固定区确认时，应用会暂停并保留原始帧和上一版可导出画面。恢复原窗口尺寸/缩放、确认固定区或排除临时问题后，可直接点击“继续”，无需从头捕获。为了防止内存或画布失控，仍设有帧数、像素、最大长度和连续失败等安全上限。

动态内容、视频/动画、延迟加载、非连续背景、滚动过快和复杂嵌套滚动容器仍可能导致重复、错位或无法匹配。优先框选真正滚动的内容区，每次滚动保留足够重叠，并在发现异常时尽早暂停检查原始帧。

## 13. 区域录屏

### 13.1 录制前设置

在“设置 → 录屏”中配置：

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| FPS | `12` | 允许 `1–60`，通常建议 `12–30`；越高文件越大 |
| 导出为 GIF | 开 | 开启时保存为 GIF；关闭时可保存 WebM 或 H.264 MP4 |
| 系统声音 | 关 | 开启后请求相应系统权限 |
| 麦克风 | 关 | 开启后请求麦克风权限，可与系统声音混音 |

“导出为 GIF”是 GIF 与视频之间的模式选择，并不是同时生成 GIF 和视频。

### 13.2 录制流程

1. 按 `⌘ ⇧ R`，或从主窗口/菜单栏选择“区域录屏”。
2. 框选录制区域。
3. 控制条出现后，先按需开启镜头画中画 `◉`、动作提示 `⌨`；这两项需在开始前决定。框选完成本身不会立即开始计时。
4. 点击红色开始按钮，使用暂停/继续控制录制。显示时长会扣除暂停时间。
5. 开启动作提示后，可在录制中切换成片画笔 `✎`，按住鼠标绘制红色轨迹；`⌫` 清空已有画笔轨迹。
6. 点击停止。
7. 如有需要，在保存前填写起点和终点秒数进行裁剪；终点填 `0` 表示保留到结尾。
8. 选择导出位置和格式。

启用 GIF 时保存对话框只提供 GIF。关闭 GIF 时可选 WebM 或 H.264 MP4；MP4/GIF 转换依赖随应用打包的 FFmpeg。

### 13.3 镜头画中画、动作提示与成片画笔

| 功能 | 实际行为 |
| --- | --- |
| 镜头画中画 | 明确开启后单独请求相机画面，在最终成片右下角合成圆形镜头与白色描边；不会使用相机麦克风，也不能在本次录制中自由拖动或缩放位置 |
| 动作提示 | 监听全局鼠标和部分按键，在成片中显示左右键点击环、命名键和带 `⌘`/`⌃`/`⌥` 的快捷键提示；普通无修饰文字输入不会显示，以免录下正在键入的正文 |
| 成片画笔 | 依赖动作提示和辅助功能监听，把录制期间的鼠标拖动画成红色轨迹写进最终视频；它不覆盖桌面实时画面，也不是给其他应用使用的系统级画笔 |

动作提示和成片画笔需要 macOS“辅助功能”权限。全局事件监听意外中断时，应用会停止提示层并给出警告，屏幕录制本身继续。

相机启动失败、权限被拒绝或没有设备时，应用会明确提示并释放本次未开始的捕获；相机选项随后降级为不可用，点击“开始”重试即可录制纯屏幕。若相机在录制过程中断开，旧镜头帧会被移除，屏幕录制继续；当前录制不能热重连相机。

### 13.4 Retina 与多显示器尺寸

录屏会定位框选所在的目标显示器，并以桌面视频流的实际 `videoWidth`/`videoHeight` 计算输出，而不是简单相信界面缩放倍数。选区的横、纵方向会独立映射到实际像素，因此 Retina 屏幕、不同缩放比例和带负坐标的副显示器不会把同一个比例重复计算。最终画布和保存文件的宽、高是实际像素尺寸。

一次录制仍对应一个目标显示器，不支持让一个选区跨越多个显示器。自动测试覆盖了合成的 Retina、副屏负坐标与横纵比例不同场景，但混合 DPI、多屏排列和具体采集设备仍需在目标 Mac 上做真机验收。

### 13.5 取消、失败与容量限制

- `Escape` 或关闭控制条会在允许取消时放弃录制；放弃操作不会保留成品。
- 如果停止后取消保存、转换失败或保存失败，应用会尽量保留已录内容并提供“重试保存”，不会把失败当作成功。
- 如果明确启用了系统声音或麦克风，而权限/音源不可用，录制会明确失败，不会静默输出缺少该音轨的文件。
- 渲染层对单次编码 WebM 设有约 `128 MB` 上限；达到上限会停止并进入保存流程。
- 成功保存的录屏会进入历史记录。

长时间、高分辨率、高 FPS 的录制和 GIF 转换会明显增加内存、时间与磁盘占用。

## 14. 历史记录管理

### 14.1 浏览与筛选

历史页支持：

- 按“全部、区域、窗口、全屏、延时、长截图、录屏、贴图”筛选；
- 按类型、日期或时间文字搜索；
- 按“今天、昨天、具体日期”分组，并折叠分组；
- 分批加载内容，避免一次渲染大量缩略图。

### 14.2 单项操作

打开图片详情后可复制、导出、OCR、翻译、发送到 AI 或删除。录屏详情只提供导出和删除，不提供图片复制/OCR。

### 14.3 批量操作

1. 进入多选模式。
2. 勾选项目，或选择当前筛选结果中的全部项目。
3. 可批量导出到指定文件夹、把所选图片合并为多页 PDF，或批量删除。

“合并多页 PDF”只接受图片历史项，每张图生成一页。页面顺序按图片进入选择集合的先后排列；使用“全选当前”时按当前筛选列表的显示顺序排列。如果取消某项后重新勾选，它会排到当前选择末尾。保存前可据此逐项确认顺序。

单次合并至少 1 张、最多 100 张图片，输入总量不超过 256 MB；录屏、缺失文件或非图片条目不能混入。应用会弹出保存对话框并生成一个 `.pdf`，文件名使用截图模板，`{type}` 为历史 PDF 类型，`{width}`/`{height}` 取第一页像素尺寸。

“清空历史记录”和删除操作会删除应用私有历史库中的相应条目，无法从应用内恢复；它们不会删除之前另存到其他目录的导出文件。

## 15. 设置

多数普通设置会即时保存；AI Key、端点、模型和提示词通过设置页底部的“保存 AI 配置”统一保存。

| 分组 | 可配置内容 |
| --- | --- |
| 通用 | 开机自启动、启动时是否打开主窗口、截图保存目录、浅色/深色主题 |
| 全局快捷键 | 区域截图、OCR、长截图、录屏、贴剪贴板、恢复贴图、划词翻译 |
| 内置快捷键 | 截图取消/确认/选择/取色/历史/最近选区，以及贴图锁定/置顶/选字/穿透/缩略 |
| 截图 | 自动复制、自动贴图、自动保存到历史、默认导出格式、质量、截图文件名模板 |
| 录屏 | FPS、GIF/视频、系统声音、麦克风、录屏文件名模板 |
| OCR | 本地或大模型引擎，以及 9 种单语言和 8 种“对应语言 + English”组合 |
| AI 模型 | DeepSeek、MiniMax、更多 OpenAI 兼容服务或智能分流；Key、Base URL、模型和公共提示词 |
| 存储与隐私 | 查看历史数量、清空历史、阅读数据边界说明 |

默认状态为：启动时打开主窗口；不开机自启；保存目录为空（即系统“图片”目录）；浅色主题；截图后不自动复制、不自动贴图、不自动进历史；PNG、质量 90；截图文件名 `困困截图-{timestamp}`；录屏 12 FPS、导出 GIF、不采集系统声音和麦克风，文件名 `困困录屏-{timestamp}`；本地“简体中文 + English”OCR；AI 提供方为 DeepSeek，但没有预置用户 API Key。

录制全局快捷键时，点击输入框后直接按组合键；`Escape` 取消录入，`Backspace`/`Delete` 清空。内置快捷键只接受单个主键。

## 16. 启动参数与自动化入口

启动参数可以直接进入受控截图流程，但它不是无头 API：仍会显示图形界面，也仍需 macOS 权限。

### 16.1 支持的参数

```text
--capture=region       区域截图
--capture=fullscreen   全屏截图
--capture=window       窗口截图
--capture=ocr          截图并 OCR
--capture=long         长截图
--capture=record       区域录屏
--delay=1..300         延时秒数，仅可与 region 或 fullscreen 组合
```

等号形式和分隔形式都可识别，例如 `--capture region`。缺少值、重复参数、未知模式、非整数延时或超出 `1–300` 会直接报错，不会猜测执行。应用已经运行时，再次启动传入的合法参数也会交给现有单实例处理。

### 16.2 从源码调用

```bash
npm start -- --capture=region
npm start -- --capture=fullscreen --delay=5
npm start -- --capture=window
npm start -- --capture=ocr
npm start -- --capture=long
npm start -- --capture=record
```

### 16.3 调用已安装应用

```bash
"/Applications/困困截图工具.app/Contents/MacOS/困困截图工具" --capture=region
"/Applications/困困截图工具.app/Contents/MacOS/困困截图工具" --capture=fullscreen --delay=5
```

直接运行可执行文件时，终端可能保持与应用进程关联；这不影响第二次启动参数由现有应用接收。

## 17. 数据位置、备份与隐私

核心本地数据位于：

```text
~/Library/Application Support/困困截图工具/
```

也可以右击菜单栏图标，选择“打开数据文件夹（历史/配置）”。主要内容如下：

| 路径 | 内容 |
| --- | --- |
| `config.json` | 普通设置、快捷键和经过安全存储加密的 AI Key 表示 |
| `history/index.json` | 历史元数据索引 |
| `history/images/` | 历史截图副本 |
| `history/media/` | 历史录屏等媒体副本 |
| `pin-workspace/index.json` | 正常退出时仍打开的贴图状态 |
| `pin-workspace/images/` | 跨重启恢复所需的贴图图片副本 |

备份时应先彻底退出应用，再复制整个“困困截图工具”数据目录。不要在应用运行时手工编辑索引文件，否则可能与正在写入的状态冲突。

隐私边界：

- 截图、录屏、历史和贴图工作区默认只保存在本机，没有内置云同步。
- 本地 OCR 不把识别内容发送到网络，也不会联网下载语言包。
- 只有用户主动执行 AI、AI 翻译、划词翻译、测试连接或刷新模型列表时，才按[第 11 节](#11-ocr-ai-与联网数据边界)所述发起网络请求。
- API Key 必须成功通过系统安全存储加密后才允许落盘。
- “复制”会把内容写入 macOS 系统剪贴板；其他能读取剪贴板的应用可能访问它。
- 手动导出的文件位于用户选择的目录或系统“图片”目录，不受“清空历史记录”控制。
- 应用没有自动更新器，不会因检查更新而自行联系发布服务器。

## 18. 故障排查

### 18.1 截到黑屏、壁纸或空白

1. 打开“系统设置 → 隐私与安全性 → 屏幕录制/屏幕与系统录音”。
2. 确认已允许“困困截图工具”；源码模式确认 Electron 或终端条目。
3. 从菜单栏右键菜单彻底退出，再重新打开。
4. 先测试全屏截图，再测试区域和窗口截图，以区分权限与选区问题。

### 18.2 全局快捷键无反应

- 从主窗口按钮或菜单栏菜单测试功能本身是否正常。
- 到“设置 → 全局快捷键”换一个组合。
- 检查 macOS、输入法、窗口管理器和其他截图软件是否占用了相同按键。
- 如果设置提示注册失败，原组合不会生效；请选择新的组合键。

### 18.3 改完权限仍不生效

主窗口关闭后菜单栏进程可能仍在运行。必须从右键菜单选择“退出困困截图工具”，确认菜单栏图标消失后再启动。

### 18.4 录屏没有声音或无法开始

- 确认“系统声音”和“麦克风”是分别开启的；默认都关闭。
- 检查对应系统权限，并完全重启应用。
- 确认麦克风没有被其他独占程序占用。
- 如果明确要求的音源不可用，当前设计会直接报错；请修复权限/设备后重试，而不是寻找一份可能已静默降级的文件。
- 如果是镜头画中画启动失败，确认相机权限与设备；提示出现后也可再次点击“开始”，按纯屏幕模式继续。
- 动作提示或成片画笔不可用时，请开启“辅助功能”权限并完全重启应用；成片画笔只写入导出画面，不会显示在桌面实时预览上。

### 18.5 录屏停止后没有文件

- 查看控制条是否显示“重试保存”。取消保存或转换失败时，录制内容会尽量保留在那里。
- 确认目标目录可写且磁盘空间充足。
- 长录制或 GIF 转换需要更多时间；不要在转换中强制退出。
- 单次编码数据接近 128 MB 时会主动停止并进入保存。

### 18.6 OCR 失败或结果不准

- 扩大选区，保留清晰文字，减少阴影、透视、透明背景和无关图形。
- 在设置里从 9 种单语言或对应的“语言 + English”组合中选择与内容匹配的一项。
- 本地语言包缺失会明确报错；重新安装可信完整包，不要期待它自动联网下载。
- 截图工具栏 OCR 固定走本地引擎；若需要大模型 OCR，请从相应 AI/OCR 面板使用，并先配置服务商。

### 18.7 AI 报未配置、连接失败或结果异常

- 确认选择的提供方、Base URL、模型和 Key 相互匹配，并点击“保存 AI 配置”。
- “智能分流”必须同时配置 DeepSeek 与 MiniMax。
- DeepSeek 和“更多服务商”的图片任务会先本地 OCR；若希望模型直接看图，请选择 MiniMax。
- “测试连接”和“刷新模型列表”本身需要网络，也可能受代理、服务商地区、余额或限流影响。
- AI/OCR 输出可能错误；重要内容应人工核验。

### 18.8 长截图重复、断裂或提前停止

- 开始前选对纵向/横向。
- 缓慢、匀速滚动，每次保留足够重叠区域。
- 暂停视频、动画和自动刷新的内容；对固定头部/底栏使用自动建议或手动填写固定区域。
- 如果页面使用嵌套滚动区，重新框选真正变化的内容区域。
- 发现坏帧时先暂停，从原始帧列表删除后重拼；删除或固定区调整不满意可撤销/重做。
- 连续抓帧、宽度或显示缩放异常后，先恢复目标窗口状态，再点“继续”；原始帧和上一版结果仍会保留。
- 导出前用顶部/底部裁边去掉首尾冗余；这不会破坏原始帧。

### 18.9 贴图没有出现、显示空白或无法点击

- 按 `⌘ ⇧ P` 没有任何反应时，先从菜单栏右键菜单直接执行“贴出剪贴板内容”。如果菜单入口正常，请到“设置 → 全局快捷键”确认“贴出剪贴板内容”没有留空，也没有被系统或其他应用占用。
- 从截图编辑器点击“贴图”时，先等待选区底图和工具栏正常显示；底图尚未解码或已失败时会阻止输出，不会继续生成透明贴图。
- 贴图窗口提示“贴图显示失败”时点击“重试显示”。替换图片失败会保留上一张成功画面；如果仍失败，可重新复制/截图后再贴。
- 贴图显示的是黑色原画面而不是加载错误时，先测试一次全屏截图，并检查“屏幕录制/屏幕与系统录音”权限。受保护视频或 DRM 内容也可能不允许被正常捕获。
- 贴图存在但无法点击时，很可能开启了鼠标穿透。按 `⌘ ⌥ P` 取消全部贴图穿透，再用 `P` 控制单个贴图。

### 18.10 重启后找不到已关闭贴图

`⌘ 3` 的“最近关闭”只保证当前会话。跨重启恢复的是应用正常退出时仍保持打开的贴图工作区；已手动关闭、全部销毁或异常退出前未成功写入的贴图不在此范围。

### 18.11 保存失败或历史中没有截图

- 检查目标目录权限、磁盘空间和文件名。
- “自动保存到历史”默认关闭；仅复制不会自动进历史。
- “保存”和“快速保存”成功后会另存历史副本，即使自动历史关闭。
- 编辑器在保存失败时会尽量保留现场，请先解决路径问题再重试。

## 19. 当前已知限制

- 当前是 macOS 优先的预览版；不承诺 Windows/Linux 支持，也不能用自动测试代替目标 Mac 上的真机验收。
- 项目没有自动更新器。当前仓库没有可证明公开构建已完成正式 Developer ID 分发签名和 Apple 公证的凭据或记录。
- 长截图仍需用户人工滚动；动态内容、复杂滚动容器、延迟加载和快速滚动可能造成拼接异常。原始帧是当前窗口内的临时工作区，取消或关闭后不能作为工程继续编辑。
- 贴图目前只能把所有已打开贴图编为一组，没有任意子集、多组管理或嵌套分组界面；裁剪、旋转和翻转会把当前合成标注烘焙进新底图。
- 离线公式贴图支持 KaTeX 语法子集，不支持完整 LaTeX 宏包环境。
- 镜头画中画目前固定在成片右下角，不能在本次录制里拖动/缩放；启动失败需再次开始以进入纯屏幕录制，录制中断线不能热重连。成片画笔不会成为桌面实时覆盖层。
- 一次区域录屏只属于一个目标显示器，不能跨屏框选。Retina、混合 DPI、多显示器负坐标、相机、系统声音、麦克风、权限提示、AVIF/PDF 兼容性、窗口捕获和贴图跨重启恢复，都应在目标 macOS 与实际硬件上验收。
- GIF 转换可能很慢并产生较大文件；录屏单次编码数据约有 128 MB 上限。
- OCR 精度取决于图片质量、语言和版面；Vision 文字框、条码识别和 AI 结果也可能出错。
- 原位翻译在复杂排版、竖排文字、密集表格或字体变化较大的页面上可能覆盖不准。
- DeepSeek 与通用 OpenAI 兼容提供方当前不直接看图；图片先做本地 OCR，复杂表格和公式的结构信息可能丢失。
- AI 功能依赖第三方服务的网络、Key、模型可用性、限流、余额、隐私政策和计费规则。
- 全局快捷键可能被系统或其他应用占用。
- 最近关闭贴图栈只属于当前会话且最多 10 项；跨重启恢复与它是两套不同机制。
- Finder 文件贴图当前不包含在“全部保存”批处理结果中。
- 历史多页 PDF 只接受图片，单次最多 100 张且输入总量不超过 256 MB；正式分享前应检查选择顺序和每页内容。
- 历史和贴图工作区只保存在本机，没有内置云同步或跨设备同步。
