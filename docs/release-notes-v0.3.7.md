# v0.3.7：手动滚动长截图，复制与保存分开

日期：2026-09-07。目标平台：macOS / Apple Silicon（arm64）。

> 本文记录本轮源码交互和已执行的自动化证据；构建完成后的提交 SHA、CI、安装包 SHA-256、安装与下载核验记录写入 [GitHub Release](https://github.com/shier-12-zwf/kunkun-shot/releases/tag/v0.3.7)，不把源码通过等同于产物通过，也不沿用旧版结果。

## 本轮交互

1. **手动滚动，自动拼接**：进入长截图后自动采集首帧；你将鼠标放回选区内，自己缓慢向下滚动。工具只负责采样和拼接，不发送自动滚动操作，选区外的预览显示已拼接结果。
2. **默认复制**：主操作由“完成”改为“复制”。点击按钮，或在工具条获得焦点时按 `Enter` / `⌘ C`，把长图写入剪贴板；无需先选保存位置。随后到支持粘贴图片的目标应用按 `⌘ V`。
3. **独立保存**：另设“保存”按钮，工具条获得焦点时也可按 `⌘ S`；选择文件位置保存图片，格式沿用截图导出设置、默认 PNG，不改动剪贴板，不再把保存和复制串成一个动作。
4. **保留结果以便重试**：复制或保存成功后结束本次长截图；取消保存对话框、保存失败或复制失败时，暂停采集并保留当前长图和本次会话中的原始帧，可重新复制、保存或点击“继续”恢复采集。工具条“取消”才表示放弃整次长截图；关闭或取消后，临时帧不能作为工程恢复。

方向、暂停/继续、片段调整、固定顶部/底部、撤销/重做和导出裁边沿用已有流程。默认纵向；如需横向，应在只有首帧时切换。保留两帧后方向锁定。

## 使用流程

按 `⌘ ⇧ A` 框选需要滚动的正文 → 点击翻译左侧“长截图” → 等待自动首帧 → 将鼠标放回选区内，自己向下滚动 → 观察帧数和长图尺寸增长 → 点击“复制” → 到目标应用按 `⌘ V`。

需要文件时，最后一步改点“保存”并选择位置即可。取消保存不会丢弃长图，可以回来改点“复制”。完整功能说明见 [使用指南第 12 节](使用指南.md#12-长截图)。

`Enter`、`⌘ C`、`⌘ S` 与 `Escape` 只在长截图工具条获得焦点时处理，不是全局快捷键。焦点在原页面时，按键仍由原应用接收；优先直接点击对应按钮。输入框和下拉框不会触发导出；Tab 聚焦到按钮后，Enter 执行该按钮本身的操作，例如“保存”不会变成复制。

## 本轮拼接修复

- 修复末尾 1～2px 的真实位移被判为静止、造成长图缺尾的问题。
- 同时检查正文前景一致性，防止白色页边掩盖亚像素动画中的错位文字；浅灰固定栏不能同时被当作背景和对齐证据。
- 重叠至少覆盖约 10% 正文，避免重复短脚注造成几乎跨越整屏的假匹配；较大重复内容仍保留歧义保护，不强行选择一个候选。
- 低对比纹理、轻微图像色差仍可正确接入；坏中间帧被拒绝后，后续稳定帧可以继续接入。重叠不足时稍停或回滚一点，再沿原方向继续；已拼接内容保持不变。

复制出口调用现有原生图片剪贴板 IPC，不是复制图片路径或 Data URL 字符串。自动化验证导出的完整 PNG 和复制/保存调用边界，未逐一实测微信、浏览器编辑器等目标应用的系统 `⌘ V`；能否粘贴还取决于目标应用是否接受图片。
