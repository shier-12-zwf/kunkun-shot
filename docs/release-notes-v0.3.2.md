# 困困截图工具 v0.3.2 发布说明

> 发布日期：2026-09-05
> 定位：macOS 早期预览版的稳定性更新

v0.3.2 集中处理长截图、贴图显示、截图工具栏翻译入口，以及 IPC 与操作反馈中的高频问题。它不改变已有用户数据格式，也不引入自动更新器。

## 本版重点

- “翻译”继续位于截图主工具栏第一位；紧凑的目标语言选择器现在直接位于按钮旁边，不再藏在“更多”菜单中，随后才是 OCR。
- 长截图控制条会完整钳制在当前显示器可见区域，并覆盖全屏选区、负坐标副屏和控制条宽于屏幕等边界。
- 长截图删除、重拼、撤销与重做使用事务式状态更新；合成或画布渲染失败时回滚到上一份可用状态，避免时间线与画面分叉。
- 长截图只保留当前结果、时间线和撤销/重做历史仍可到达的原始帧；达到像素预算时会回收不可达帧，必要时裁剪最旧的撤销快照。
- 贴图窗口将成功解码的同一个图片节点直接提交为可见内容，避免探测图片成功后再次加载造成偶发空白；页面每次重新载入后，主进程都会补发最新贴图内容。
- 打开设置或 AI 面板等窗口的 IPC 返回可结构化克隆的状态对象；截图、历史记录、复制与配置保存会区分成功、取消、忙碌、失败或部分成功。
- 依赖与锁文件移除 `ffmpeg-static`，新安装包不得捆绑独立 FFmpeg CLI；录屏默认改为未剪辑 WebM，可选格式和裁剪按系统 FFmpeg 的实际能力启用或降级。

## 使用方式

1. 从菜单栏退出正在运行的旧版本，避免旧进程继续占用全局快捷键或窗口状态。
2. 如需保留回退能力，先备份当前应用；用户设置与历史记录位于独立数据目录，正常覆盖应用不会主动清除它们。
3. 发布检查清单完成后，从 GitHub Release 获取本轮全新构建并通过负向扫描的唯一 DMG 应用附件（不提供应用 ZIP），并在安装前阅读下方“Release 附件、签名与公证边界”。
4. 安装并启动后，按系统提示复核“屏幕录制”、麦克风、摄像头等实际要使用的权限。
5. 建议先完成一次区域截图、贴图、纵向长截图，并在截图工具栏直接切换目标语言后执行翻译。

完整功能、权限、数据边界和故障排查见 [使用指南](使用指南.md)。

## 关键修复说明

### 翻译入口

框选完成后的主工具栏按“翻译 → 目标语言 → OCR”排列。点击语言选择器即可从主工具栏切换目标语言；点击“翻译”后仍会按当前选择执行。复制或保存包含译文的截图时，应先确认翻译层已经完成渲染。

### 长截图

- 支持纵向页面和横向表格的手动抓帧、暂停/继续、删帧重拼、撤销/重做及继续采集。
- 控制条位置同时考虑选区、显示器工作区与控制条自身尺寸，避免全屏和多显示器场景下跑到屏幕外。
- 时间线编辑先在候选状态中完成合成与渲染，成功后再提交；失败会保留上一份正确结果和仍可继续操作的时间线。
- 原始帧按可达性保留，降低长会话中删除与重做反复操作造成的内存持续增长。

长截图仍依赖页面存在足够稳定的重叠区域。动态广告、视频、重复纹理、纯色大块、反向滚动或缩放/DPR 中途变化，都可能令匹配失败；失败提示出现后，可暂停、删除异常帧并从上一正确结果继续。

### 贴图

- 图片只有在完成解码后才替换当前可见内容；同一个已解码节点直接进入页面，减少二次资源加载竞态。
- 贴图页面因刷新、崩溃恢复或其他原因重新载入时，会重新获得最新内容。
- 如果某张图片本身损坏或不可解码，窗口会保留可理解的失败状态，而不会把探测成功误当作实际显示成功。

### IPC 与用户反馈

- 窗口打开类 IPC 不再返回不可序列化的 Electron 窗口对象。
- 主界面的区域截图、长截图与录屏入口会在请求期间防止重复触发，并区分完成、取消、已有任务占用和真正失败。
- 历史记录加载失败不再伪装成“没有记录”，可直接重试；批量操作会报告部分失败。
- 复制和翻译配置保存只在主进程确认后显示成功，避免操作实际失败时仍出现误导性提示。

### 媒体导出与系统 FFmpeg

- PNG、JPEG、PDF 和未剪辑 WebM 不依赖外部 FFmpeg；WebP、BMP、AVIF、GIF、H.264 MP4 与录屏裁剪调用用户另行安装的系统 FFmpeg。
- 可执行文件存在不代表所有格式都可用：具体导出仍取决于该 FFmpeg 构建是否包含目标编码器与滤镜。应用及新安装包不得复制或捆绑 `ffmpeg-static`、`ffmpeg`/`ffprobe` CLI。
- 新配置默认保存 WebM。旧配置若请求 GIF 而系统无可用 FFmpeg，会提示并自动回退 WebM；若还请求裁剪，必须由用户明确选择保存完整未剪辑 WebM 或取消，取消/失败后保留录制内容以便重试。
- 允许的录屏目标后缀是：无 FFmpeg 时仅 `.webm`；有 FFmpeg 的非 GIF 模式仅 `.webm`/`.mp4`；GIF 模式仅 `.gif`。保存对话框的格式过滤器只是选择提示；本版同时在主进程写入/转换前执行严格后缀校验，并用完整后缀矩阵自动化测试覆盖集合外输入。

## Release 附件、签名与 Apple 公证边界

除 GitHub 平台自动生成的源码归档外，v0.3.2 Release 只人工附加 **1 个本轮全新构建且通过检查的 DMG**，不附应用 ZIP；本地生成的应用 ZIP、blockmap 与 `latest-mac.yml` 不作为 Release 附件。

较早生成的 v0.3.2 候选 DMG 在 `app.asar.unpacked/node_modules/ffmpeg-static/ffmpeg` 中包含独立 FFmpeg CLI；该程序自身报告含 nonfree 组件且“not legally redistributable”。因此，这个旧 DMG 及其先前记录的大小、SHA-256、签名/冒烟结果均已撤回，**不得发布、复用或作为当前版本证据**，同一旧输出目录中的其他产物也不得使用。

新 DMG 已从源码提交 `6298bcfbc64a4167e76dbc0dd854f2f74294d235` 与空输出目录生成；构建门禁列出 `app.asar`、递归检查 `app.asar.unpacked`，并只读挂载 DMG 复检其中应用，确认没有 `ffmpeg-static` 包/路径和独立 `ffmpeg`/`ffprobe` CLI。Electron Framework 自带的 `Libraries/libffmpeg.dylib` 是 Chromium 媒体运行库，不是独立 CLI，不得误删或误判。负向扫描、完整性和签名检查均已通过，实际产物为：

- 文件：`困困截图工具-0.3.2-arm64.dmg`
- 大小：150,055,866 字节（约 143.10 MiB）
- SHA-256：`3be42139c620ae74ef8ef5a93e8ac37fbdc8f4b706ab124fa530a6f825611e78`

DMG 外层容器**不单独 codesign**；DMG 内的 `.app` 使用固定本机开发证书 `KUN Translator Local Signing` 签名，目的是在同一台 Mac 上维持开发安装身份，并尽量保持 TCC 权限连续性。该应用无 Team ID、不启用 Hardened Runtime。它是供了解这些限制的用户使用的测试/预览包，仍须明确区分：

- DMG 内应用不是 Apple Developer ID 签名；
- DMG 和其中应用均**未经 Apple 公证**，也没有 stapled notarization ticket；
- 它不是正式 Gatekeeper 首次打开或异机兼容性验证；
- GitHub 上可下载不改变其测试/预览属性，也不构成 Apple 正式分发证明；
- 只应在理解上述风险后用于本地安装与更新测试。

若未来要把安装包作为面向一般用户的正式 Apple 分发产物，仍需使用 Developer ID 身份完成 Hardened Runtime、Apple 公证、ticket 装订、Gatekeeper/异机验收和许可证盘点。不得将本机证书签名 DMG 描述为“Apple Developer ID 已签名”“已公证”“Gatekeeper 已验证”或“异机已验证”。

## 已知限制

- 当前没有自动更新器；版本更新仍需人工安装。
- 长截图采用手动滚动与重叠匹配，不保证所有动态或低纹理页面一次成功。
- 贴图、长截图、多显示器/Retina、摄像头、音频和 macOS 权限仍需在目标机器上做真机验收，自动化测试不能替代这些检查。
- 本地 OCR 离线运行；AI、翻译或视觉模型请求是否联网，取决于用户主动配置并触发的服务。
- 可选媒体格式与裁剪取决于用户系统 FFmpeg 的具体编码器/滤镜能力；无外部 FFmpeg 时默认未剪辑 WebM 仍可用。
- 录屏保存对话框过滤器不能单独证明后缀已被严格限制；主进程后缀矩阵已自动化覆盖，但真实保存面板的手工输入仍属于目标机器验收范围。
- v0.3.2 提供一个通过本轮门禁的知情测试/预览 DMG；它不是 Apple 公证安装包，本轮不提供应用 ZIP。
